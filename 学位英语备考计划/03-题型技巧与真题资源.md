# 题型技巧与真题资源

## 考试概况

学位英语考试（主流通用版本，具体请对照你所在省份/学校的考试通知微调）：

| 项目 | 内容 |
|---|---|
| 考试时长 | 120 分钟 |
| 题目总数 | 85 题左右 |
| 题型 | 词语用法与语法结构、阅读理解、挑错、完形填空、英汉互译 |
| 词汇要求 | 领会式约 4400 词 + 550 词组；复用式约 2000 词 |
| 及格线 | 通常为总分的 60%（各地略有差异，以本地通知为准） |
| 是否考写作/听力/口语 | 主流版本不考，部分省份版本有差异，请以当地考试通知为准 |

**建议的考场时间分配（120分钟）**

| 题型 | 建议用时 | 说明 |
|---|---|---|
| 词语用法与语法结构 | 20分钟 | 单题耗时短，果断作答，不要纠结 |
| 阅读理解 | 35分钟 | 占分比重最大，优先保证质量 |
| 挑错 | 15分钟 | 按"四类错误"快速定位 |
| 完形填空 | 25分钟 | 先通读全文再做题 |
| 英汉互译 | 20分钟 | 直译为主，语句通顺即可 |
| 检查/涂卡 | 5分钟 | 预留出来，不要卡着时间才涂卡 |

## 1. 词语用法与语法结构

**题型特点**：单句选择题，考查语法点和词语辨析（对应语法手册①-⑱专题）。

**做题步骤**
1. 先看四个选项，判断考点类型（时态？从句？介词搭配？固定短语？）
2. 找句子主干（主谓宾），确定空格在句子中的成分
3. 代入排除法：先排除明显不搭配语法规则的选项
4. 拿不准时优先选"更常见、更简单"的搭配，而非生僻用法

**易错提醒**：这类题目大部分考点集中在语法手册的18个专题里，考前把手册的"易错点"部分反复看，命中率最高。

---

## 2. 阅读理解

**题型特点**：3-4 篇短文，每篇后附 4-5 道题，通常占分比重最大。

**做题步骤（先题后文法）**
1. 先扫一遍题干（不看选项），带着问题去读文章，效率更高
2. 阅读时留意：首尾句（主旨题）、转折词 but/however/although（态度题）、数字和专有名词（细节题）
3. 定位到原文对应句子后再看选项，避免凭印象选
4. 遇到生词不要停下来查，根据上下文猜意思，实在猜不出就跳过继续读

**常见题型对策**
- 主旨大意题：看首段和末段，注意作者的态度词
- 细节题：回原文定位关键词（人名、数字、专有名词最容易定位）
- 推理判断题：找"言外之意"，选项通常是原文内容的合理引申，而非原句照抄
- 词义猜测题：看该词所在句子的上下文关系（同义替换/对比关系）

---

## 3. 挑错

**题型特点**：一句话中划出4个部分，选出有错误的一处。

**四类常见错误（考前重点看这四类）**
1. **主谓不一致**：主语是单数但谓语用了复数形式（或反之）
2. **词性错误**：该用形容词的地方用了副词，或该用名词的地方用了动词
3. **时态/语态错误**：时态前后不一致，或该用被动语态却用了主动
4. **固定搭配错误**：介词/连词使用错误（如 depend in 应为 depend on）

**做题步骤**：先通读全句理解意思，再逐一检查四个划线部分是否符合上述四类错误，不要只孤立看某个单词。

---

## 4. 完形填空

**题型特点**：一篇短文挖去10-20个空，四选一。

**做题步骤**
1. **先通读全文（不做题）**，理解文章大意和逻辑关系，尤其是首句（通常不挖空，是理解全文的关键）
2. 边读边做，优先解决词义辨析明显、语法明显的空
3. 拿不准的空，利用前后文的逻辑关系词（but/so/because/however）判断
4. 全部做完后，通读一遍检查上下文是否连贯

**易错提醒**：完形填空考的不只是单词意思，还考"逻辑关系"和"固定搭配"，做题时要联系上下文，而不是孤立判断某个词对不对。

---

## 5. 英汉互译

**题型特点**：几句英译汉 + 几句汉译英。

**英译汉技巧**
- 用 [`05-句子拆解与翻译速查表.md`](./05-句子拆解与翻译速查表.md) 的固定算法：找谓语→找主语→取主干→括修饰→识别逻辑→按中文重组。
- 优先保证“谁对谁做了什么”正确，再追求中文自然；特别检查主动/被动、否定范围、代词指代和逻辑连接。
- 不逐词对齐，但不添加原文没有的原因、态度或结论。

**汉译英技巧**
- 先确定句子的时态和主谓结构，再填充其余成分
- 优先使用你有把握的简单句型、常见词汇，不要为了"高级"硬用生僻词导致语法错误
- 检查：主谓一致、时态、单复数、介词搭配

**一句三译法自检**：每次练习保留①原句②自己首译③修订稿，并只标记错误类型（主干/时态/语态/逻辑/词义/中文表达）。每周统计最多的两类，下周优先练。
