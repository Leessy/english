# 句子拆解与翻译速查表

> 目标：像读代码一样读英语。先找“主干”，再看“参数和修饰”，最后根据中文习惯重组。遇到生词时，只要能识别句子结构，仍然可以理解大意。

## 1. 词性就是单词的“类型”

| 词性 | 缩写 | 在句子中做什么 | 常见位置 | 例子 |
|---|---|---|---|---|
| 名词 | n. | 表示人、物、事、概念 | 冠词/形容词后；作主语或宾语 | a useful **tool** |
| 代词 | pron. | 代替名词，避免重复 | 主语或宾语位置 | **It** helps **us**. |
| 动词 | v. | 表示动作或状态，决定句子结构 | 通常在主语后 | Users **need** help. |
| 形容词 | adj. | 说明名词的性质，或放在系动词后作表语 | 名词前；be/look/seem 后 | a **simple** rule; It is **simple**. |
| 副词 | adv. | 说明动作的方式、程度、时间等 | 位置灵活 | work **quickly**; **usually** works |
| 介词 | prep. | 引出时间、地点、对象、方式 | 后接名词/代词/doing | **in** the file; **for** you |
| 连词 | conj. | 连接词、短语或句子 | 两个结构之间 | A **and** B; leave **if** needed |
| 冠词 | art. | 标记名词是泛指还是特指 | 名词前 | **a** file; **the** file |
| 限定词 | det. | 限定数量、所属、指代范围 | 名词前 | **this/my/some** file |

**快速判断词性**：`-tion/-ment/-ness` 常是名词；`-ful/-less/-ive/-able` 常是形容词；`-ly` 常是副词。这只是线索，不是没有例外的规则，例如 `friendly` 是形容词。

## 2. 五种基本句型：句子的最小骨架

| 结构 | 含义 | 英文 | 准确中译 |
|---|---|---|---|
| S + V | 谁 + 做什么 | The program **stopped**. | 程序停止了。 |
| S + V + O | 谁 + 对什么做什么 | The function **returns a value**. | 该函数返回一个值。 |
| S + linking V + C | 谁/什么 + 是/变得/看起来 + 什么状态 | The option **is useful**. | 这个选项很有用。 |
| S + V + IO + DO | 谁 + 给谁 + 什么 | Send **me the log**. | 把日志发给我。 |
| S + V + O + C | 谁 + 使/称什么 + 成为什么 | This makes **the code easier**. | 这会让代码更容易理解。 |

S = 主语，V = 谓语动词，O = 宾语，C = 补语/表语，IO = 间接宾语，DO = 直接宾语。

### 系动词和实义动词怎么分

- `The soup tastes good.`：`tastes` 连接主语和状态，“这汤尝起来味道不错”。
- `She tastes the soup.`：`tastes` 是实际动作，“她尝了尝这汤”。
- 判断法：动词后如果是在说明主语“怎么样/是什么”，它多半是系动词。

## 3. 读句子的固定算法

1. **圈出谓语**：先找有时态的动词组，如 `is required`、`has changed`、`will return`。
2. **找主语**：问“谁/什么在做这件事”。不要把介词短语里的名词误当主语。
3. **找谓语后的核心成分**：是宾语，还是说明主语状态的表语。
4. **括起修饰成分**：介词短语、从句、分词短语、插入语先放到一边。
5. **识别逻辑信号**：`but/however` 转折，`because/since` 原因，`therefore/so` 结果，`if/unless` 条件。
6. **按中文重组**：保留原意和逻辑，不强求英汉逐词对齐。

**拆解示例**：

`The configuration file that you created yesterday is loaded automatically when the application starts.`

- 主干：`The configuration file is loaded.`（配置文件会被加载）
- 定语从句：`that you created yesterday`（你昨天创建的），修饰 `file`
- 方式：`automatically`（自动地）
- 时间从句：`when the application starts`（应用启动时）
- 自然中译：**应用启动时，会自动加载你昨天创建的配置文件。**

## 4. 助动词 + 动词形式速查

| 看到的结构 | 核心理解 | 例子 | 中译 |
|---|---|---|---|
| do/does + 原形 | 疑问/否定/强调的一般现在时 | Does it work? | 它能正常工作吗？ |
| did + 原形 | 疑问/否定/强调的一般过去时 | Did it fail? | 它失败了吗？ |
| be + doing | 正在进行 | It is running. | 它正在运行。 |
| have/has + done | 已经发生，与现在有关 | It has changed. | 它已经发生了变化。 |
| had + done | 在另一个过去时间之前已发生 | It had stopped before we arrived. | 我们到达前，它就已经停止了。 |
| be + done | 被动：主语是动作承受者 | Access is denied. | 访问被拒绝。 |
| modal + 原形 | 能、可以、必须、应该、可能 | You should retry. | 你应该重试。 |
| modal + have + done | 对过去的推测/评价 | It may have failed. | 它可能已经失败了。 |
| to + 原形 | 目的、计划、待做事项 | Click to continue. | 单击以继续。 |
| 介词 + doing | 介词后的动作当名词用 | before restarting | 重启之前 |

> `to` 不总是不定式标志。`look forward to using it` 里的 `to` 是介词，所以后面用 `using`。

## 5. 过去分词的四种常见读法

| 用法 | 例子 | 理解 |
|---|---|---|
| 完成时 | We have **fixed** the issue. | 我们已经修复了该问题。 |
| 被动语态 | The issue was **fixed**. | 该问题已被修复。 |
| 形容词化的状态 | The issue is **fixed** now. | 该问题现在已经解决了。 |
| 后置/前置修饰 | the **selected** item / data **returned** by the API | 选中的项 / API 返回的数据 |

`be + done` 要结合上下文判断“被动动作”还是“结果状态”。`The door was closed by Tom.` 明显是被动；`The door is closed.` 通常只是“门关着”的状态。

## 6. 长句中的边界信号

| 信号 | 通常引出 | 理解方式 |
|---|---|---|
| who/which/that/whose | 定语从句 | 先找它前面被修饰的名词，译成“……的” |
| when/where/why | 时间/地点/原因从句 | 先判断它是修饰名词还是表示情境 |
| that/whether/what/how | 名词性从句 | 整个从句当一个“事情” |
| if/unless/provided that | 条件 | 如果/除非/只要 |
| although/while/however | 让步或转折 | 尽管/而/然而 |
| because/since/due to | 原因 | because/since 后接句子；due to 后接名词 |
| therefore/thus/as a result | 结果 | 因此/从而/结果 |

## 7. 英译汉的准确性检查

1. **主干对不对**：谁做了什么？主动和被动有没有译反？
2. **时间对不对**：`has done` 不要机械译成“曾经”；它常强调现在的结果。
3. **否定范围对不对**：`not all` 是“并非所有”，不是“所有都不”。
4. **逻辑关系对不对**：`unless` = “除非/如果不”，不要再多加一层否定。
5. **代词指什么**：`it/this/they/which` 要回到上文找指代对象。
6. **多义词选对没有**：`issue` 可以是“问题、议题、期号、发布”，要看搭配和语境。
7. **中文是否自然**：可以调整语序、补出必要的量词，但不能添加原文没有的结论。

## 8. 英文文档高频句型

| 模板 | 常见译法 |
|---|---|
| X is used to do Y. | X 用于做 Y。 |
| X allows/enables you to do Y. | X 使你能够做 Y。 |
| X is required/optional. | X 是必需的/可选的。 |
| X consists of A and B. | X 由 A 和 B 组成。 |
| X depends on Y. | X 取决于 Y。 |
| X refers to Y. | X 指的是 Y。 |
| If omitted, X defaults to Y. | 如果省略，X 默认为 Y。 |
| Make sure that X is enabled. | 请确保 X 已启用。 |
| Note that X does not support Y. | 请注意，X 不支持 Y。 |
| X may result in/lead to Y. | X 可能导致 Y。 |
| For more information, see X. | 有关更多信息，请参阅 X。 |
| This feature is deprecated. | 此功能已弃用（尚可能可用，但不建议继续使用）。 |

## 9. 日常交流的最小可用句型

| 功能 | 句型 | 中译 |
|---|---|---|
| 打招呼 | How's it going? | 最近怎么样？ |
| 表达需要 | I need some help with this. | 我需要别人帮我处理一下这个。 |
| 礼貌请求 | Could you say that again? | 你能再说一遍吗？ |
| 确认理解 | Do you mean ...? | 你的意思是……吗？ |
| 表示没听懂 | I didn't quite catch that. | 我刚才没太听清。 |
| 表达看法 | I think this is better. | 我觉得这个更好。 |
| 委婉不同意 | I'm not sure I agree. | 我不太确定自己是否赞同。 |
| 询问建议 | What do you suggest? | 你有什么建议？ |
| 表示稍等 | Give me a moment, please. | 请稍等一下。 |
| 结束交流 | Thanks for your time. | 谢谢你抽时交流。 |

## 10. 每天 10 分钟的使用方法

1. 从真题或英文文档中选 2 句，用斜线分块。
2. 标出 S/V/O/C，圈出连词，标记动词形式。
3. 先只译主干，再把修饰成分放回去。
4. 对照准确性检查表修改中译。
5. 口头说 2 个“日常最小句型”，只替换其中的名词或动词。
