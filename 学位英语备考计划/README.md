# 学位英语 + 英文文档阅读 + 日常交流（分级基础 + 8 周冲刺）

主目标是通过学位英语考试，同时建立英文文档阅读和简单日常交流能力。学习路线像学编程语言：**先识别词性和动词形式，再掌握基本句型，然后拆长句，最后在真题、文档和交流中反复调用。**

## 快速上手

1. 先通读 `04` 的代词、be/助动词和动词形式，再学 `07` 第 0 层；每天 1 单元，不要同时背 800 词表。
2. 通过 `07` 末尾的测试后，开始 `08` 第 1 层；每天 5 行，学 3 天复习 1 天。
3. 第 1 层学习期间再并行考试语法；通关后，把 `02` 的 800 词作为第 2 层考试/书面词扩展。
4. 每周日会有查漏补缺和词组学习任务，不要跳过——这是巩固记忆的关键环节
5. 第4、7、8周有真题模拟安排，请提前从 `03-题型技巧与真题资源.md` 底部的链接下载真题

## 词汇体系说明

**800 个精记词不足以支撑“无障碍阅读”**，也不应一开始全部精背。NGSL 的 2809 通用词对一般英语平均约有 92% 覆盖；Nation 的研究估计，接近 98% 的无辅助阅读覆盖往往需要 8000-9000 词族。本项目因此把目标拆为“先用少量词读懂受控句子→逐步扩大真实文本覆盖”。

- **第 0 层（约120词）**：超级高频功能词、助动词和基础动词；要求秒懂、会拆句、会替换造句。
- **第 1 层（约240词）**：次高频日常词和文档词；要求在例句中认出并理解。
- **第 2 层（800词）**：原精学词表，定位调整为考试和书面阅读扩展，不再作为零基础第一批词。
- **泛记词（3237个）**：只配音标、词性、中文释义，不要求记住，只求"看到能反应出大概意思"，每周约400个，工作日80个/天快速扫一遍
- **常用词组（300个）**：配中文释义、例句、例句翻译
- **优先工作集**：`06` 中的词与词块不另外追求数量，与大词库有重复，作用是标出最应该先掌握的部分。
- `07/08` 与 4037 词库有重复，不另外累加词汇量；它们的作用是把必须先掌握的词重新排序并放入例句。

## 重要说明

- **Markdown 文件是当前最新源版本**。目录中现有 PDF 是旧版快照，尚不包含本次新增的句子拆解、高频词和新计划，学习时优先使用 `.md` 文件。
- 计划按"工作日60-75分钟、周末2小时以上"设计。如果时间不够，优先保留高频词、精学词、新语法和每天 2 句拆解；泛记词和练习量可以酌情减半。
- 不同省份/学校的学位英语题型可能略有差异（例如部分省份还考写作或完成对话），本资料按最主流的通用版本编写，使用前建议对照你所在省份的考试通知确认题型是否一致。
