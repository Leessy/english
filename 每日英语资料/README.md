# Daily English · 每日英语资料

当前面向：能看懂多数基础例句，但反应慢，常忘记词义、不规则词形、代词或词块的自学者。目标是通过反复阅读逐渐读顺日常消息、工作信息与入门说明。

## 怎么学

打开 [index.html](./index.html)，默认进入“常用句复现”。每次 3–10 分钟：读几句 → 卡住时点词 → 合上提示重读 → 有余力读一段。已会的基础不要求重学，结构真正卡住时再进“句式分层”。

当前材料包含：

- 108 条原创复现句：18 组各 6 句；先练生活与工作，再看文档长句，最后处理压缩与混合结构。
- 8 篇短文 + 3 篇分章原创故事；每篇故事约 600 词、4 章，有明确学习目标、逐句中译和结构提示。
- “核心词与词块”收拢 144 个通用与生活核心条目、28 个优先词块；每项至少在 2 个不同例句中出现。另有 61 条复现补充句，重点补足问句、三单、过去式、分词、代词指代和常用搭配。
- “动词形态复现”覆盖 41 个重点动词：新增 225 条场景例句（生活 105、工作 80、IT 40），并复用原有例句和故事。201 项先学词形／用法各有至少 3 条不同语境，另有 7 项明确后学。
- 原 12 组、36 条分层例句、12 道换句题及 3 段阶段短文，供按需补漏。
- 随文词库包含 740 个提示条目（含功能词、缩写、部分词形和人名），166 个动词有五形态，78 组词块有整体解释。这不是独立词汇量、严格词频排名或必须背完的清单；词形复现保证只针对上述 41 个重点动词，不泛指全部 166 个。

原题型视图、旧文章、自动组合句库和旧大词库均已从页面移除，不再作为运行依赖。原始文件留在仓库供追溯，不在导航中展示。目录已改为 `每日英语资料`，项目内链接同步更新；旧外部书签需改用新路径。

## 点词提示怎样用

句中的每个英文词都是按钮，支持鼠标、触屏和键盘。点击后在原页显示：

- 一般词义与“本句提示”分开；语境注释不会作为其他句子的语法结论套用。
- 不规则动词回到原形，并列出原形、三单、过去式、过去分词和 -ing 形式。原材料有标注时突出本句词形；没有标注时明确说明同形歧义，不自动猜时态。
- 人称代词显示同组主格、宾格、物主限定词、独立物主代词和反身代词；已标注的句子还说明指代对象。
- 识别缩写与词块，例如 `I’d`、`FYI`、`get used to`、`back up`。`I’d` 未标注时显示 would/had 两种可能，不一律猜成一种。
- 可以分别收藏“单词＋原句”或“词块＋原句”，到“我的词块”中遮住释义复习。重复收藏同词头会更新例句，不无限添加重复项。

句末“译”、复现卡“整句对照”和词汇页的例句按钮都能就地打开中译与解析。弹窗里还可点词、返回整句、切换上下句；关闭后回到触发位置，不必翻到底部。长篇每次只显示一章，自动保存章号；“读完整篇”按钮在最后一章可用，仍由学习者自行确认，不是理解测试。

提示卡只使用本地材料，不向外部词典发送所读句子。未收录词明确显示缺少可靠释义，不拼造翻译。当前 638 条主学习流及补充材料（共 6,837 个英文词次，归一后涉及 598 个提示词头）的英文词均通过本地覆盖检查；一条材料可能包含两句，不以标点强行拆分。统计不包含 3 段旧阶段整段练习的覆盖承诺，也不代表需要预先掌握 598 词才能阅读。覆盖检查不等于语义质量的自动保证。

详细路线见 [从熟词到复杂句](../英语系统入门计划/00-轻量阅读入门/03-从熟词到复杂句.md)。基础小课仅作补漏，不要求从 `I am` 重来。

## 记录怎样保存

复现保存当前句和“待熟练／这次读顺”；动词形态保存所选动词和形态；文章保存当前篇、章号与整篇阅读遍数；分层训练保留旧课号和层级；词块收藏独立保存。记录代表练习经历，不是掌握率。一次阅读中的重复点击不会多计“读完”次数。

仅使用当前浏览器的 `localStorage`；不上传、不跨设备同步。禁用或无法保存时页面仍可读，并提示手记位置。清除读句记录需要确认，且不会清除旧词库的生词标记。设备朗读取决于浏览器和已安装的英语语音。

## 词频核查与学习顺序

旧资料是人工选词，并不是按语料频率排序；原 12 组主要补阅读结构，也不是最常见口语句式排行榜。本轮先补 do/did/can 提问、存在句、指代、动作时态、因果条件与请求确认，后置复杂分词和混合从句。`back up`、`API` 等归入 IT 按需词，不冒充通用口语最高频词。

参照 [Oxford 3000 的选词原则](https://www.oxfordlearnersdictionaries.com/about/oxford3000)：兼顾频率、跨文本分布和学习实用性；参考 [NGSL 的通用英语范围](https://www.newgeneralservicelist.com/new-general-service-list)。这些来源支持选词方向，不构成本项目逐条词频名次认证。本项目没有导入这些词表，也没有逐词完成全表比对。

800 词适合作为起步范围，不是任意资料都读得懂的门槛。NGSL 的 2,809 个词头在其研究的一般文本中约覆盖 92% 词次，但词次覆盖不等于理解率。本项目显示的“出现于 N 句”只计本站不同例句，不是外部英语频率；同形词与多义词仍要看语境。

## 动词形态怎样反复练

打开 [动词形态复现](./index.html?view=verbs)，每次选一个最近常卡住的动词，再选一种形态，读完 3 条即可。先辨认整句意思，再点目标词看“为什么用这个形态”，合上提示重读；下次先复习，再切换过去式或过去分词做对比。3 条是材料覆盖的最低要求，不是看过 3 次就掌握的保证。

场景包括吃喝点餐、作息休息、乘车出行、付款账单、电话问候、确认需求、会议安排、工作进度、文件存放与应用提示。新增 `eat / drink / sleep / pay / speak / listen` 进入核心词组；代词、否定、连接词和常用词块随句重复，不要求另背大表。

统计按人工标注的实际语法作用去重：`I put...` 的过去式与 `I have put...` 的过去分词分开；同一条出现两次不算两条。`be` 的 `am / is / are / was / were` 分开练；`read` 的过去式与过去分词提示读 /red/。`-ing` 同时包含进行时和活动作主语等常见非谓语用法，不一律译为“正在”。

先学范围是 35 个通用动词加 6 个生活动词。后学项为 `know / want / see / need / mean / understand` 的 `-ing` 和 `mean` 的过去分词用法。这些形式并非不存在；部分状态义通常不用进行时，部分形式涉及额外义项。参照 [British Council 的状态动词说明](https://learnenglish.britishcouncil.org/free-resources/grammar/b1-b2/stative-verbs)，例如 `I think...`（认为）与 `I’m thinking about...`（正在考虑）要分义理解；具体后学顺序是本站的教学取舍。

## 分章故事怎么用

| 原创故事 | 长度 | 本次目标 |
|---|---|---|
| 门边的蓝盒子 | 637 词，4 章 | 借出与送人的误会；代词所属、过去动作、原因与结果 |
| “做完了”到底是什么意思？ | 594 词，4 章 | 确认需求与工作状态；do/did/done、内容从句 |
| 没有回应的按钮 | 616 词，4 章 | 用户反馈与排查；条件、先后顺序、it/its 指代 |

一次一章约 150 词：第一遍跟情节，只查影响理解的词；第二遍精看 1–2 句；下次先用英语或中文复述上一章。故事含少量过去完成时和关系从句，属于受控进阶练习，未经 CEFR 等级认证；若每句都卡住，先回短文。它们不是《Who Moved My Cheese?》的转载、节选或改写。

## Mac 朗读与音色设置

旧代码只设置英语语言，并未指定音色，且三个入口分别使用 0.82 / 0.85 / 0.9 倍速。依 [MDN voice 文档](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/voice)，未设置 voice 时由浏览器选择默认匹配音色；不能仅靠代码断言用户实际听到了哪种声音。

现在所有入口统一使用 `reader-speech.js`：等待音色列表、监听 [voiceschanged](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/voiceschanged_event)、明确选择英语音色，自动选择时避开已知特效音色；默认 1 倍速、正常音高。支持试听、换音色、保存语速、停止，长文逐句排队，切篇或切章停止旧音频。

在 Mac 上先点页面顶部“朗读设置”试听。若没有合适音色，按 [Apple 官方说明](https://support.apple.com/en-euro/guide/mac-help/mchlp2290/27/mac/27)，在系统设置 → 辅助功能 → 朗读与语音（旧版本叫“朗读内容”）下载英语语音，完成后刷新列表或重开浏览器。网页不保证能访问全部系统音色。`read` 等同形异音词优先听整句，合成语音也可能读错。

页面本身不上传朗读文本，但浏览器标记为非本地的语音服务可能联网处理文本；离线使用请选择标注“设备”的音色。自动测试验证了路由与播放逻辑，未在真实 Mac 上验证音质。

## 资料质量与保留范围

旧自动组合语料未经逐句校对，不应重新接入默认学习流。新例句和短文均为原创教学材料，不冒充新闻、研究或特定产品的真实文档。

已理解结构后，先在不同场景复现，再逐步读更长段落。阅读熟练度不会自动变成听说能力；设备朗读只是辅助，后续仍需真人音频和实际交流。

## 本地运行与检查

这是无构建步骤的静态站，可直接打开 HTML；更稳定的方式是在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器访问本机 `http://127.0.0.1:8765/每日英语资料/`。服务器只监听本机，不代表发布到外网。切换文件模式与 HTTP 模式后，浏览器记录可能不共用。

无需第三方依赖的检查（从仓库根目录）：

```sh
node 每日英语资料/tools/check-content.cjs
node 每日英语资料/tools/test-speech.cjs
```

浏览器回归需另外安装 Playwright，设置 Node 搜索路径；不属于网站运行依赖。例如：

```sh
npm install --prefix /tmp/lc-english-preview playwright --no-save --package-lock=false
NODE_PATH=/tmp/lc-english-preview/node_modules node 每日英语资料/tools/test-browser.cjs
```

默认使用 `/usr/bin/google-chrome`；可用 `CHROME_PATH` 覆盖。默认访问上面的本地服务器地址；可用 `ENGLISH_TEST_URL` 覆盖为以 `/` 结尾的站点地址。测试只在隔离浏览器上下文中创建记录，不改个人浏览器资料。

内容检查不能自动证明翻译与语法完全准确，语言内容仍需人工校对。
