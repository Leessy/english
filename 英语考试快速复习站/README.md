# 英语快速复习站

当前面向：认识一些英语单词和基础 `be` 用法，但读整句不熟练的自学者。目标是理解日常消息、熟悉领域的入门说明，逐步具备自主阅读能力。

## 怎么学

打开 [index.html](./index.html)，默认进入“每次练一句”。每次用 3–10 分钟，只推进一层：回忆上一句 → 读当前例句 → 看同页提示 → 合上解释重读 → 有余力再做换句题。

当前主线包含：

- 12 组常用结构，每组 3 层原创例句，共 36 句。
- 12 道新句理解题，避免只凭熟悉原句作答。
- 第 4、8、12 组后的 3 段整段阅读，含词义提示、理解问题和中译。
- [47 项读句配套词](./vocabulary.html)，含常用动作、连接词、状态词及原创例句。它们是教学优先项目，不是严格频率榜；无需先背完。

原有代词表、词形表、文章拆解、大词库仍可按需查阅。历史题型只作旧资料，不属于当前学习主线。目录名保留，避免破坏旧书签和已有链接。

详细路线见 [从熟词到复杂句](../英语系统入门计划/00-轻量阅读入门/03-从熟词到复杂句.md)。基础小课仅作补漏，不要求从 `I am` 重来。

## 记录怎样保存

课号和层级在切换时自动保存；完成换句题后，点击“记录本组练习”才累计已练组数。第一次答错的组标记待巩固。记录表示练习经历，不表示考试分数或掌握率。

仅使用当前浏览器的 `localStorage`；不上传、不跨设备同步。禁用或无法保存时页面仍可读，并提示手记位置。清除读句记录需要确认，且不会清除旧词库的生词标记。设备朗读取决于浏览器和已安装的英语语音。

## 资料质量与保留范围

原 `data/sentence-library.js` 是自动排列组合的语料，曾作为“1500+ 句”主线，其中存在不可数对象配 `are`、状态动词机械套进行时等问题。本轮保留原文件，但已停止在页面加载；未经逐句校对，不应重新接入默认学习流。

新主线例句手工编写，按“完整块 → 小句关系 → 嵌套组合”递进。词库不再将“800 个有例句条目”称为足够的阅读词汇门槛。原大词库和历史文章未在本轮逐条全面校对，来源信息不代表学习优先级或严格词频。

## 文件分工

| 文件 | 用途 |
|---|---|
| `index.html` | 主入口，保留原有拆句、文章和历史资料视图 |
| `reading.js` / `reading.css` | 主线交互、练习记录、渐进展示与手机布局 |
| `data/reading-path.js` | 12 组结构、36 条递进例句、12 道换句题 |
| `data/reading-vocabulary.js` | 47 项配套词，与大词库合并时按词头去重 |
| `vocabulary.html` | 默认配套词，完整词库供搜索查询 |
| `tools/check-content.cjs` | 数据结构、脚本语法、重复 ID、本地文档链接检查 |
| `tools/test-browser.cjs` | 浏览器交互、恢复记录、移动端与存储降级回归检查 |

## 本地运行与检查

这是无构建步骤的静态站，可直接打开 HTML；更稳定的方式是在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器访问本机 `http://127.0.0.1:8765/英语考试快速复习站/`。服务器只监听本机，不代表发布到外网。切换文件模式与 HTTP 模式后，浏览器记录可能不共用。

无需第三方依赖的检查（从仓库根目录）：

```sh
node 英语考试快速复习站/tools/check-content.cjs
```

浏览器回归需另外安装 Playwright，设置 Node 搜索路径；不属于网站运行依赖。例如：

```sh
npm install --prefix /tmp/lc-english-preview playwright --no-save --package-lock=false
NODE_PATH=/tmp/lc-english-preview/node_modules node 英语考试快速复习站/tools/test-browser.cjs
```

默认使用 `/usr/bin/google-chrome`；可用 `CHROME_PATH` 覆盖。默认访问上面的本地服务器地址；可用 `ENGLISH_TEST_URL` 覆盖为以 `/` 结尾的站点地址。测试只在隔离浏览器上下文中创建记录，不改个人浏览器资料。

内容检查不能自动证明翻译与语法完全准确，语言内容仍需人工校对。
