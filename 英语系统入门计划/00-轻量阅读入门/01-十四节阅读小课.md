# 十四节阅读小课

> 本文现在是基础补漏，不是默认必修。如果 `I am / is / are` 已会，只是连句读不顺，直接用 [每次练一句](../../每日英语资料/index.html?view=reading) 的 12 组递进训练。遇到具体基础缺口再回对应课。

每次只学一课的一部分。今天 10 分钟：回忆一句 → 看词义和例句 → 回答三问。只有 3 分钟：只完成第一句。忘记的词直接看同页提示。

这些词按本课程的使用价值挑选，不是语料库的严格频率排名。每课只选最多 3 个当前陌生、又值得复用的词重点记，其他词允许反复看本页。`/` 是断句提示，不是原句标点。

阅读时问：**说谁或什么？是什么状态或做什么？有没有“不/必须/可以”？什么时候或什么条件下？** 先理解，再学习名称。

每课三问答对两问、并在核对后弄清否定和条件，就可以继续。错的那一句留到下次开头复习，不限反应速度。

## 第一课：认出谁是什么状态

今天只看：`人或东西 + am/is/are + 状态`。am/is/are 都是 be 的形式，连接“谁”和“什么状态”；中文常常不用译出“是”。

同页词卡：`I` 我；`you` 你/你们；`it` 它；`am/is/are` 是/处于；`ready` 准备好了；`busy` 忙；`small` 小；`the` 这里说的那个；`file` 文件。

| 英文 | 分块 | 意思 |
|---|---|---|
| I am ready. | I / am ready | 我准备好了。 |
| You are busy. | You / are busy | 你很忙。 |
| It is small. | It / is small | 它很小。 |
| The file is small. | The file / is small | 这个文件很小。 |

只熟悉 `I am`、`you are`、`it is`。`The file` 是一个东西，跟 it 一样用 is。ready、busy、small 是描述词，语法名称是“形容词”。

自己试读：`The file is ready.`

三问：①这句谁准备好了？②`I am ready.` 是“我在准备”，还是“我已准备好”？③`I am busy.` 是什么意思？

<details><summary>先回答，再核对</summary>

①文件。②已经准备好，描述状态。③我很忙。此处 am 不表示“正在做”。

</details>

下次复习：`The file is ready.` → 文件准备好了。

## 第二课：认出这是什么和后文的 it

回忆：`The file is ready.` = 文件准备好了；`is ready` 描述状态。

同页词卡：`this` 这/这个；`is` 是；`a` 一个；`the` 已知或特定的那个；`my` 我的；`your` 你的；`book` 书；`file` 文件；`it` 它；`new` 新的；`small` 小的。

| 英文 | 结构 | 意思 |
|---|---|---|
| This is a book. | This / is / a book | 这是一本书。 |
| This is my book. | This / is / my book | 这是我的书。 |
| This is your file. | This / is / your file | 这是你的文件。 |
| It is new. | It / is new | 它是新的。 |

`my book` 和 `your file` 各是一个整体。my/your 后面带书、文件等事物名称。后一句 it 接着指前一句的 file，不必再重复名称。

连续读：`This is a file. The file is small.` 首次引入用 a，第二次特指刚说的文件用 the；这是常见用法，其他用法后续再学。

三问：①`This is my file.` 是谁的文件？②`This is a book. It is new.` 中 it 指什么？③`my new book` 是“我新书”还是“我的新书”？

<details><summary>核对答案</summary>

①我的。②刚提到的书。③我的新书，整块谈一本书。

</details>

下次复习：`This is my file. It is new.` → 这是我的文件。它是新的。

## 第三课：认出谁做什么

回忆：`This is my file.` = 这是我的文件；my file 一起读。

同页词卡：`I` 我；`we` 我们；`you` 你；`it` 它；`have` 有；`use` 使用；`need` 需要；`a` 一个；`book` 书；`file` 文件；`help` 帮助。

| 英文 | 结构 | 意思 |
|---|---|---|
| I have a book. | I / have / a book | 我有一本书。 |
| We use it. | We / use / it | 我们使用它。 |
| I need help. | I / need / help | 我需要帮助。 |
| You have a file. | You / have / a file | 你有一个文件。 |

have/use/need 是动词，这里表示拥有、使用、需要。它们前面不额外加 am/is/are：`I need help.` 已经完整。

连续读：`I have a file. We use it.` 第二句 it 指第一句 file。陌生技术名词可以先当作“某个东西”，保住主干。

三问：①`We need help.` 谁需要帮助？②`I have a book. I use it.` 中 it 指什么？③`I am need help.` 多了什么？

<details><summary>核对答案</summary>

①我们。②书。③多了 am；应是 I need help。

</details>

下次复习：`I need help.` → 我需要帮助。

## 第四课：认出 she uses 和 it has

回忆：`I need help.` = 我需要帮助；need 是这句的动作核心。

同页词卡：`she/he/they/it/I` 她/他/他们/它/我；`use/uses` 使用；`need/needs` 需要；`have/has` 有；`a/the` 一个/特指；`book` 书；`file` 文件；`help` 帮助。

| 英文 | 看见什么 | 意思 |
|---|---|---|
| I use the file. | I + use | 我使用这个文件。 |
| She uses the file. | she + uses | 她使用这个文件。 |
| He needs help. | he + needs | 他需要帮助。 |
| They have a book. | they + have | 他们有一本书。 |
| She has a book. | she + has | 她有一本书。 |

这些句子说明通常情况，用“一般现在时”。主语是 he/she/it 或单个东西时，普通动词常加 -s；have 的对应形式是 has。先做到 `uses → use 的形式 → 使用`。

三问：①`She needs a file.` 她需要什么？②`He has a book.` 的 has 是“有”还是“已经”？③`They use it.` 是什么意思？

<details><summary>核对答案</summary>

①一个文件。②有；后面接的是 a book。③他们使用它。

</details>

下次复习：`She has a file. She uses it.` → 她有一个文件。她使用它。

## 第五课：认出否定

回忆：`She uses it.` = 她使用它；uses 来自 use。

同页词卡：`I/you/it` 我/你/它；`am/is` 是/处于；`ready` 准备好；`not` 不；`do/does` 此处帮助表达否定或疑问；`need` 需要；`help` 帮助；`work` 起作用；`don't` = do not；`doesn't` = does not；`isn't` = is not。

| 英文 | 必须整块读 | 意思 |
|---|---|---|
| I am not ready. | am not ready | 我还没准备好。 |
| It isn't ready. | is not ready | 它还没准备好。 |
| I don't need help. | do not need | 我不需要帮助。 |
| It doesn't work. | does not work | 它不起作用。 |
| Do you need help? | Do ... need? | 你需要帮助吗？ |

be 后直接加 not；need/work 这类普通动词的一般现在时否定通常请 do/does 帮忙。does 已带了单数变化，后面 work 不加 -s。

三问：①`It doesn't work.` 是能用还是不能用？②`I don't need help.` 要不要帮助？③`It is ready.` 和 `It isn't ready.` 哪个没准备好？

<details><summary>核对答案</summary>

①不能正常起作用。②不需要。③第二句。否定读反时，把这组对照再读一次。

</details>

下次复习：`It doesn't work.` → 它不起作用。

## 第六课：认出操作指令

回忆：`It doesn't work.` = 它不起作用；doesn't 含否定。

同页词卡：`open` 打开；`close` 关闭；`save` 保存；`read` 阅读；`please` 请；`don't` 不要；`the` 这里的；`door` 门；`book` 书；`file` 文件；`it` 它；`and` 并且/然后。

| 英文 | 谁执行 | 意思 |
|---|---|---|
| Please open the door. | 暗含“你” | 请打开门。 |
| Read the book. | 暗含“你” | 读这本书。 |
| Open the file. | 暗含“你” | 打开文件。 |
| Save it and close it. | 同一个人做两件事 | 保存它，然后关闭它。 |
| Don't close it. | 暗含“你”，动作被禁止 | 不要关闭它。 |

以动词原形开始、告诉读者做什么，叫“祈使句”。它可以省略 you，不必寻找一个写出来的主语。界面按钮也常这样写。

三问：①`Open the book.` 谁打开？②`Don't save it.` 是让你保存吗？③`Open the file and read it.` 中 it 指什么？

<details><summary>核对答案</summary>

①你，也就是读者/听者。②不是，是不要保存。③文件。

</details>

下次复习：`Open the file. Don't close it.` → 打开文件。不要关闭它。

## 第七课：认出哪里有什么

回忆：`Open the file.` 是指令，open 用原形。

同页词卡：`there is` 有一个/有某种东西；`there are` 有多个；`a` 一个；`two` 二；`book/books` 书/多本书；`file/files` 文件/多个文件；`desk` 桌子；`folder` 文件夹；`on` 在……上；`in` 在……里；`the` 这里的。

| 英文 | 分块 | 意思 |
|---|---|---|
| There is a book. | There is / a book | 有一本书。 |
| There are two books. | There are / two books | 有两本书。 |
| The book is on the desk. | The book / is / on the desk | 书在桌上。 |
| There is a file in the folder. | There is / a file / in the folder | 文件夹里有一个文件。 |

`there is/are` 整块表示“有”，这里 there 不单独译成“那里”。`in the folder` 是地点块。名词 books/files 的 -s 表多个，与第四课动词 uses 的 -s 作用不同。

三问：①`There are two files.` 有几个文件？②`The file is in the folder.` 文件在哪里？③`There is a book on the desk.` 是有人正在写书吗？

<details><summary>核对答案</summary>

①两个。②文件夹里。③不是，在说桌上有一本书。

</details>

下次复习：`There is a file in the folder.` → 文件夹里有一个文件。

## 第八课：认出可以、必须和需要做

回忆：`There is a file.` = 有一个文件。

同页词卡：`I/you` 我/你；`can` 能/可以；`cannot/can't` 不能；`must` 必须；`must not` 禁止；`need to` 需要做；`don't need to` 不需要做；`open/save/leave` 打开/保存/离开；`it` 它；`now` 现在。

| 英文 | 先读这一块 | 意思 |
|---|---|---|
| You can open it. | can open | 你可以打开它。 |
| You can't open it. | cannot open | 你无法/不可以打开它，具体看语境。 |
| You must save it. | must save | 你必须保存它。 |
| You must not open it. | must not open | 你不得打开它。 |
| I need to leave now. | need to leave | 我现在需要离开。 |
| You don't need to save it. | don't need to save | 你不必保存它。 |

can/must 后接动词原形；`need to + 动词原形` 表示“需要做”。前面的词给后面的动作增加能力、许可或必要性。

三问：①`must not` 是不必还是禁止？②`don't need to` 是不必还是禁止？③`I can save it.` 能不能保存？

<details><summary>核对答案</summary>

①禁止。②不必。③能。第①②问读反就留到下次重点复习。

</details>

下次复习：`You don't need to save it.` → 你不必保存它。

## 第九课：认出 if 和 before/after

回忆：`You must not open it.` = 你不得打开它。

同页词卡：`if` 如果；`before/after` ……之前/之后；`you/I` 你/我；`am` 处于；`need/help` 需要/帮助；`call` 给……打电话；`me` 我（动作的对象）；`save/close` 保存/关闭；`file` 文件；`it` 它；`the` 特指；`lunch` 午饭；`busy` 忙。

| 英文 | 分块 | 意思 |
|---|---|---|
| If you need help, call me. | If you need help / call me | 如果需要帮助，给我打电话。 |
| Save the file before you close it. | Save the file / before you close it | 关闭文件前先保存。 |
| Open it after lunch. | Open it / after lunch | 午饭后打开它。 |
| I am busy before lunch. | I am busy / before lunch | 午饭前我很忙。 |

if 后面给出条件；before/after 决定先后。`call me` 中 me 也是“我”，但接在 call 后承受动作；`I call` 中 I 是做动作的人。

三问：①第一句在什么条件下打电话？②第二句先保存还是先关闭？③`Open it before lunch.` 与第三句顺序一样吗？

<details><summary>核对答案</summary>

①需要帮助时。②先保存。③不同，一个午饭前，一个午饭后。

</details>

下次复习：`Save it before you close it.` → 关闭它之前先保存。

## 第十课：认出正在做

回忆：`Save it before you close it.` 先保存，后关闭。

同页词卡：`I/she/it` 我/她/它；`am/is` 此处帮助构成进行；`read/reading` 读/读的 -ing 形式；`work/working` 工作或运行/其 -ing 形式；`wait/waiting` 等待/其 -ing 形式；`a` 一本；`book` 书；`the` 特指；`app` 应用；`now` 现在；`busy` 忙。

| 英文 | 完整动作块 | 意思 |
|---|---|---|
| I am reading a book. | am reading | 我正在读一本书。 |
| She is working now. | is working | 她现在正在工作。 |
| I am waiting. | am waiting | 我正在等待。 |
| The app is working. | is working | 这个应用正在正常运行。 |

`be + 动词的 -ing 形式` 在这些句子里表示正在进行。这里 is 是帮手，不能把 `is working` 拆译为“是工作”。

对照：`She is busy.` = 她很忙，busy 是状态；`She is working.` = 她在工作。遇到 be，先看后面在说明什么。

三问：①`I am reading.` 在做什么？②`She is working.` 是说她昨天工作了吗？③`It is working now.` 现在能正常运行吗？

<details><summary>核对答案</summary>

①读东西。②不是，此处说正在工作。③能。

</details>

下次复习：`She is working now.` → 她现在正在工作。

## 第十一课：认出过去发生的事

回忆：`She is working now.` = 她现在正在工作。

同页词卡：`I/she` 我/她；`was` am/is 的过去形式；`busy` 忙；`open/opened` 打开/过去打开了；`save/saved` 保存/过去保存了；`go/went` 去/过去去了；`didn't` = did not，过去的否定；`the` 特指；`file` 文件；`home` 家；`yesterday` 昨天。

| 英文 | 过去线索 | 意思 |
|---|---|---|
| I was busy yesterday. | was；yesterday | 我昨天很忙。 |
| I opened the file. | opened | 我打开了这个文件。 |
| She went home. | went 是 go 的过去式 | 她回家了。 |
| I didn't save the file. | didn't save 整块读 | 我没有保存这个文件。 |

本课只记 `was / opened / saved / went`，不用扩展整张表。didn't 已表示过去否定，save 恢复原形。

三问：①`I was busy.` 描述现在还是过去？②`She went home.` 她去了哪里？③`I didn't open the file.` 文件有没有被我打开？

<details><summary>核对答案</summary>

①过去。②家。③没有。

</details>

下次复习：`I didn't save the file.` → 我没有保存这个文件。

## 第十二课：认出被做和已经做

回忆：`I didn't save the file.` = 我没有保存文件。

同页词卡：`I` 我；`the` 特指；`file` 文件；`is` 此处帮助构成被动；`saved` 保存的过去分词；`automatically` 自动地；`have` 此处帮助表示完成；`finished` 完成的过去分词；`work` 工作。

| 英文 | 看前后组合 | 意思 |
|---|---|---|
| I saved the file. | I + 过去式 saved | 我保存了文件。 |
| The file is saved automatically. | file + is saved | 文件会自动保存。 |
| I have saved the file. | I + have saved | 我已经保存了文件。 |
| I have finished the work. | I + have finished | 我已经完成了工作。 |

`is saved` 中，文件是被保存的对象；`have saved` 中，我已做过保存，事情与现在有关。saved 两处长得一样，作用靠组合判断。

“过去分词”是动词的一种形式，本身不决定过去时间。这里 `be + 过去分词` 表被动，`have + 过去分词` 表完成。完成形式也可表示经历或持续，这里先理解“已经做完”。

三问：①第二句是文件在保存别人吗？②第三句已经保存了吗？③`I have finished the work.` 是正在开始还是已经完成？

<details><summary>核对答案</summary>

①不是，文件被保存。②已经保存。③已经完成。

</details>

下次复习：`The file is saved automatically.` → 文件会自动保存。

## 第十三课：读一条完整工作消息

回忆：`I have saved the file.` = 我已经保存文件。

先试读；陌生词可以马上看下面的小词卡。

> I have a new file. It is in the folder. You can open it after lunch. Please read it. If you need help, call me. Don't change it.

同页词卡：`I/you/it/me` 我/你/它/我（接在动作后）；`have` 有；`a/the` 一个/特指；`new` 新的；`file` 文件；`is` 是/处于；`in` 在……里；`folder` 文件夹；`can` 可以；`open` 打开；`after` ……后；`lunch` 午饭；`please` 请；`read` 读；`if` 如果；`need` 需要；`help` 帮助；`call` 打电话；`don't` 不要；`change` 改动。

只新增一个动作：`change = 改动`。这里 it 一直指 file。

三问：①文件在哪里？②什么时候可以打开？③允许修改吗？

<details><summary>核对含义和结构</summary>

①文件夹里。②午饭后。③不允许。

我有一个新文件。它在文件夹里。你可以在午饭后打开它。请读一下。需要帮助时给我打电话。不要修改它。

- `I / have / a new file`：谁拥有什么。
- `It / is / in the folder`：什么在什么位置。
- `You / can open / it / after lunch`：许可 + 动作 + 对象 + 时间。
- `If you need help / call me`：条件成立时做什么。
- `Don't change / it`：禁止某个动作。

</details>

下次遮住翻译重读，确认还记得位置、时间和禁止的动作。

## 第十四课：读一段简短操作说明

回忆：`Don't change it.` = 不要修改它。

> Open the app. There is a file in the folder. Read the file before you change it. You can save it in the app. The file is saved automatically. If the app doesn't work, close it and open it again.

同页词卡：`open/close` 打开/关闭；`app` 应用；`the/a` 特指/一个；`there is` 有；`file` 文件；`in` 在……里；`folder` 文件夹；`read` 读；`before` ……之前；`you/it` 你/它；`change` 修改；`can` 可以；`save/saved` 保存/保存的分词形式；`is saved` 被保存；`automatically` 自动地；`if` 如果；`doesn't work` 不起作用；`and` 然后；`again` 再一次。

只新增 `again = 再一次`。词卡可看，先把全文意思连起来。

三问：①修改前先做什么？②是否支持自动保存？③应用不能正常运行时要做哪两个动作？

<details><summary>核对含义和关键指代</summary>

①读文件。②支持。③先关闭应用，再打开。

打开应用。文件夹里有一个文件。修改之前先读它。你可以在应用内保存文件。文件会自动保存。如果应用无法正常运行，请关闭它，然后重新打开。

- `Read the file / before you change it`：it 指 file；先读，后改。
- `The file / is saved / automatically`：文件是被保存的对象。
- `If the app doesn't work / close it and open it again`：条件句的主角变成 app，后面的 it 也指 app。

</details>
