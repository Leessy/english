# 从熟词到复杂句：当前默认路线

适合你现在的状态：知道 `I am / is / are`，也认识不少工作词，但句子连起来处理得慢。目标不是重新背最简单的单词，而是把“认得词”练成“读得出关系”。

打开 [快速复习站 · 每次练一句](../../英语考试快速复习站/index.html?view=reading)。网页包含 12 组结构、每组 3 层原创例句、1 道换句理解题，以及第 4、8、12 组后的短段阅读。常用词义、断句、主干、译文和解释都在同页。

## 1. 为什么单词认识仍然慢

例如：

> The file you sent yesterday has been saved.

不需要先把每个词翻成中文。可以暂分成：

| 读到的块 | 作用 | 理解 |
|---|---|---|
| The file | 主语中心 | 文件 |
| you sent yesterday | 说明哪个文件；省略了关系词 that | 你昨天发来的 |
| has been saved | 完整谓语：完成时＋被动 | 已经保存好了 |

主干是 `The file has been saved.`；最后还原为“你昨天发来的文件已经保存好了”。

只熟悉单词 file、sent、saved，还不能自动识别：sent 属于修饰小句，has been saved 才是主句谓语。你要练的是这种归组能力，而不是把同一组单词再背十遍。

## 2. 不一下子读复杂句：每次只加一层

```text
The file is useful.
这个文件很有用。

The file you sent is useful.
你发来的文件很有用。

The file you sent yesterday is useful because it explains the problem.
你昨天发来的文件很有用，因为它解释了这个问题。
```

`useful` 有用的；`sent` 是 send 的过去式／过去分词，本句作过去式；`because` 因为；`explains` 解释；`problem` 问题；`it` 指这个文件。

第三句不是一种全新的巨型句式：主句＋说明哪个文件＋说明原因。分层时可以暂缓读取修饰，但最终不能丢掉条件、否定或限定范围。理解了以后，要再顺着英文语序连读，而不是永远倒着翻译。

## 3. 先练什么

这里的“常用”是教学优先级，不是严格的语料频次排名。工作说明、日常消息、入门资料都能复用这些关系。

| 顺序 | 本次只抓的结构 | 读出来的意思 |
|---|---|---|
| 1 | need to / don’t need to / can do | 需要做／不必做／可以做 |
| 2 | the message on your phone | 手机上的那条消息；主语不只一个词 |
| 3 | is checking / checked / has checked | 正在检查／过去检查了／已经检查过 |
| 4 | is saved / can be saved / has been saved | 被保存／可以被保存／已经被保存 |
| 5 | if / before / unless / not … until | 条件、先后、例外条件与限制 |
| 6 | because / although / so / but | 原因、让步、结果、转折 |
| 7 | know / think + (that) 小句；whether | 知道／认为一件事；是否 |
| 8 | the file (that) you sent；people who … | 哪个东西／哪些人 |
| 9 | want to；use … to；how to | 想做；用来做；如何做 |
| 10 | people waiting；files saved here | 正在等候的人；保存在这里的文件 |
| 11 | It is important to …；Reading … helps … | 做某事很重要；某件事有助于…… |
| 12 | 多个熟悉关系组合成一句／一段 | 保持主线，补回限定和条件 |

会的层级直接略读；能不看提示说明第 3 层，并读懂换句题，就可继续。不要把所有结构同时当作今日任务，也不必等 12 组“完美掌握”才碰工作资料。

## 4. 最值得反复练的不是某一条固定句子

把句式看成带参数的模板，但不要认为英语能任意替换词。

| 常用块 | 一起学的例句 | 中文 |
|---|---|---|
| need to do | We need to check the address. | 我们需要核对地址。 |
| allow somebody to do | This app allows you to read offline. | 这个应用允许你离线阅读。 |
| help somebody (to) do | This guide helps me understand the rule. | 这份指南帮助我理解规则。 |
| make something + 形容词 | A clear name makes the file easier to find. | 清楚易懂的名称让文件更容易找到。 |
| know whether … | I don’t know whether the room is available. | 我不知道这个房间是否可用。 |
| the thing somebody did | The book I bought is useful. | 我买的那本书很有用。 |
| be ready to do | The photos are ready to download. | 这些照片可以下载了。 |
| take effect | The changes take effect after you restart the app. | 重启应用后，更改会生效。 |

同一块换一个生活场景：`We need to check the time.`（我们需要核对时间。）再换一个工作场景：`We need to check the settings.`（我们需要检查设置。）

接着变化关系：`We don’t need to change the settings.`（我们不必更改设置。）读懂这种变化，比一口气背二十个互不相干的短语更贴近当前问题。

## 5. 术语只知道够用的部分

- **谓语**：主句在说什么动作或状态。可以不止一个词，如 `has been saved`；每个从句也有自己的谓语。
- **从句**：放进大句子里的小句。例如 `I know [that it works]`；括号是“知道的内容”。
- **过去式**：用来构成一般过去时的动词形式。`I sent it yesterday.` 我昨天发送了它。
- **过去分词**：一种动词形式，名字带“过去”但本身不独立决定时间。`I have sent it.` 我已经发送了它；`It will be sent tomorrow.` 它明天会被发送。两句的 sent 都是过去分词。
- **非谓语**：动词形式没有独立承担主句时态，例如 `to save`、`files saved here` 中的 saved；先判断它是内容、目的还是修饰，不必立即背全分类。
- **系动词**：连接主角与状态／身份，如 `The instructions seem clear.`（这些说明似乎很清楚）。认识 seem 的这一用法，比只背“似乎”更有帮助。

不把所有句子都硬套“主谓宾”：`The file is useful` 是状态判断；`Save the file` 是省略主语的指令；`Reading examples helps` 则把一件事作为主语。

## 6. 每次 3–10 分钟怎样练

1. 回忆上次一句：暂不看中文，说出大意。忘记就看，随后重读。
2. 今天只读一个层级：先自己读，再展开同页词义和断句。
3. 合上提示，按意思成块朗读两遍；再换一个人、对象或时间理解。
4. 有余力做换句题。答错先找是漏词、没认出动词块，还是关系读反。

只剩 3 分钟就做第 1–2 步。隔天先复习；学了三组后，用一次时间只复习旧组；隔一周再抽几句。这个间隔是可调整的执行建议，不是精确记忆算法。

网页记住最后的课号和层级。点击“记录本组练习”才累计已练组数，初次答错会标为待巩固。已练不等于掌握；同一句做对不代表换一篇文章也能懂。浏览器禁用存储时请自己记一行位置；换设备不会自动同步。

## 7. 词汇怎么加，什么时候读真实资料

词库新入口是 [读句配套词](../../英语考试快速复习站/vocabulary.html)：47 项常用动词、连接词、状态词，每项配例句和当前用法。是回查工具，不要求先背完。原先“800 个例句词”只是资料数量，既不是充分条件，也不是开始阅读的门槛。

每次只收 1–3 个反复卡住的词块。对象名一时不认识，可以先用“某物”占位；但否定、数量限制、条件、核心动作和文档要求必须核实。

能读懂每四组后的新短段落、说明目的和限制，就选熟悉产品的一小段真实说明：一次 3–5 句。第一次读主线，第二次查决定意思的词，第三次完整读回去。若每句都有多个不懂的结构，换更短或主题更熟的材料，不要求硬扛。

阅读训练不会自动变成听说能力。读顺一句后可以听设备朗读，再试着不用原句说一个自己的版本；后续仍要加入真人录音和真实交流。

若 `don’t / can / is saved` 本身仍完全陌生，回看 [十四节基础补漏小课](./01-十四节阅读小课.md) 的对应课，不必从第一课全做。方法依据仍见 [学习设计说明](../00-学习路线/05-为什么这次缩小任务.md)。
