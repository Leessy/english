# 从短句到真实资料

完成小课后，每次只读下面一段。先不看译文回答问题；需要时看同段词卡，再核对。这里的三段都是原创迁移练习，不是外部原文。

## 1. 新的日常留言

> Your book is on my desk. I am busy now. You can read it after lunch. Please don't take it home. I need it for my work. If you need help, call me.

词卡：`your/my` 你的/我的；`book` 书；`is/am` 是/处于；`on` 在……上；`desk` 桌子；`I/you/it/me` 我/你/它/我（动作对象）；`busy` 忙；`now` 现在；`can` 可以；`read` 读；`after` ……之后；`lunch` 午饭；`please` 请；`don't` 不要；`take ... home` 把……带回家；`need` 需要；`for my work` 用于我的工作；`if` 如果；`help` 帮助；`call` 打电话。

三问：书在哪里？什么时候可以读？能带回家吗？

<details><summary>译文和答案</summary>

你的书在我的桌上。我现在很忙。午饭后你可以读它。请不要把它带回家。我的工作需要用到它。如果需要帮助，给我打电话。

答案：我的桌上；午饭后；不能。`don't take it home` 是限制条件，不能只根据 can read 理解为可以任意使用。

</details>

## 2. 新的工作消息

> I have finished the work. There are two files in the folder. The new file is ready. Please read it before lunch. Don't change the old file. If you need to change the new file, save a copy first. You can ask me for help.

词卡：`I/you/it/me` 我/你/它/我（动作对象）；`have finished` 已完成；`the/a` 特指/一个；`work` 工作；`there are` 有多个；`two` 二；`files/file` 文件；`in` 在……里；`folder` 文件夹；`new/old` 新/旧；`is ready` 准备好；`please` 请；`read` 读；`before` ……前；`lunch` 午饭；`don't` 不要；`change` 改动；`if` 如果；`need to` 需要做；`save` 保存；`copy` 副本；`first` 首先；`can` 可以；`ask me for help` 向我求助。

三问：文件夹里有几个文件？禁止改哪个？修改新文件前先做什么？

<details><summary>译文和答案</summary>

我已完成工作。文件夹里有两个文件。新文件准备好了，请在午饭前阅读它。不要修改旧文件。如果需要修改新文件，先保存一个副本。你可以向我求助。

答案：两个；旧文件；先保存副本。`need to change` 是一个动作块；`ask me for help` 暂按完整词块记。

</details>

## 3. 新的工具说明

> This app opens text files. Open a file and read it. You can change the text in the app. Your work is saved automatically. If the file is too large, the app cannot open it. Use a smaller file. Close the app after you finish the work.

词卡：`this` 这个；`app` 应用；`opens/open` 打开；`text` 文本；`files/file` 文件；`a/the` 一个/特指；`and` 然后；`read` 读；`it` 它；`you/your` 你/你的；`can/cannot` 可以/不能；`change` 修改；`in` 在……里；`work` 工作内容；`is saved` 被保存；`automatically` 自动地；`if` 如果；`is too large` 过大；`use` 使用；`smaller` 更小的；`close` 关闭；`after` ……之后；`finish` 完成。

三问：这款应用处理什么？什么条件下打不开文件？内容会自动保存吗？

<details><summary>译文和答案</summary>

这个应用可以打开文本文件。打开一个文件并阅读。你可以在应用中修改文本。工作内容会自动保存。如果文件过大，应用将无法打开它。请使用更小的文件。完成工作后再关闭应用。

答案：文本文件；文件过大时；会。`smaller` 来自 small，表示“更小”；`text files` 是“文本文件”，核心是 files。

</details>

## 4. 陌生词能不能先跳过

看这句：`You can open the container after lunch.`

即使暂不知道 container，也能先读成“你可以在午饭后打开某个东西”。这只是结构理解；若要实际执行，还需要确认它到底是什么对象。

把同句改成 `You cannot open the container before lunch.`，就变成“午饭前不能打开那个东西”。不能漏掉 cannot 和 before。

| 陌生位置 | 先怎么处理 |
|---|---|
| 人名、产品名、一次性举例的名词 | 先当一个对象，继续读主干 |
| 高频动作，如 allow、return、require | 查清当前句中的意思，整块留下例句 |
| not、only、unless、before 等 | 确认否定、范围或顺序，不按字数猜大意 |
| 定义中的核心术语、反复出现的名词 | 查清；它可能决定整段含义 |

## 5. 第一次读外部资料

下面只选一篇，不同时收藏一批：

- [British Council：Notes at work](https://learnenglish.britishcouncil.org/free-resources/reading/a1/notes-work)：官方 A1 阅读，先只读一条工作便条。
- [British Council：Text messages to a friend](https://learnenglish.britishcouncil.org/free-resources/reading/a1/text-messages-friend)：官方 A1 阅读，先只读一小段聊天。

先读英文，再做页面里的理解任务。看见陌生词时允许查；每次最多挑 3 个反复遇到、影响理解的词来记，单次偶遇词不必全部进卡片。

工作文档先选自己会用的功能：比如“打开文件”“修改一个选项”。每次读 3–5 句，不同时挑战新英语和新技术。资料中如果出现 `data returned by ...`、`the option that ...` 等尚未学过的结构，先记录这一句，之后只补对应结构。

## 6. 选材和升级规则

练顺畅阅读时，材料应大部分一眼能懂，接近每 100 个词只陌生 1–2 个更合适。含 5–10 个陌生词的材料可以用作带解释的学习材料，但常会打断阅读；覆盖率只是选材线索，不能保证理解。

连续两次面对没见过的短段落，能说出“谁做什么、何时/什么条件、哪里不能做”，就可以试稍长一点的内容。答案可以用中文，查词允许，不要求先能口头复述整篇英文。

若每句都卡住：把材料减半，给阻塞词加本句释义，下一次重读这半段。若只是一个细节不懂：查这一个点，然后继续。

声音练习可每周选两次，把已懂的一句听一遍、读一遍；找到可靠音频时再加入。朗读不能代替听力，但不用为了寻找音频中断当前阅读。
