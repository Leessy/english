# 功能词与逻辑：句子的控制流

> 名词告诉你“数据是什么”，动词告诉你“系统做什么”，功能词则决定“这些部分怎么连接”。它们往往很短，却不能跳过。

## 1. 限定词：确定你正在谈哪个对象

| 词 | 不要只背中文 | 例子 | 理解 |
|---|---|---|---|
| a/an | 一个、首次引入、任意一个 | Create **a** file. | 创建一个文件。 |
| the | 已知、唯一、上文已提到 | Open **the** file. | 打开刚才那个/指定的文件。 |
| this/that | 当前近处/当前讨论；较远/上文事情 | **This** option disables **that** feature. | 这个选项会禁用那项功能。 |
| these/those | this/that 的复数 | **These** values replace **those** defaults. | 这些值会替换那些默认值。 |
| each/every | 逐个/整体中的每个，谓语常用单数 | **Each** request has an ID. | 每个请求都有一个 ID。 |
| all/both | 所有/两者都 | **Both** methods return **all** items. | 两个方法都会返回所有项。 |
| some/any | 一些/任何、一些 | Delete **any** unused files. | 删除任何未使用的文件。 |
| no | 零个，直接限定名词 | **No** restart is required. | 不需要重启。 |

### a 和 the 在步骤中的数据流

```text
1. Create a project.      首次引入：一个新项目
2. Open the project.      已知：就是第1步创建的项目
3. Add a file to the project.  新文件 + 已知项目
```

## 2. 代词：引用已存在的对象

| 形式 | 位置 | 例子 |
|---|---|---|
| it/they | 主语 | It contains data. They contain data. |
| it/them | 动词/介词后 | Delete it. Add them to the list. |
| its/their | 名词前 | its value / their values |
| this/that | 也可指上一整件事 | The request failed. This caused a delay. |

### 指代解析算法

1. 从代词向左找距离较近的名词。
2. 检查单复数：it 通常对应单数，they 对应复数。
3. 检查意义：这个对象能否执行后面的动作？
4. this/that 可能指上一整句，不一定只指某个名词。

## 3. 介词：给参数标注角色

| 介词 | 核心角色 | 技术搭配 | 中译 |
|---|---|---|---|
| in | 容器/范围 | in the file / in memory | 在文件中/内存中 |
| on | 依赖/表面/主题 | depend on / on the server | 取决于/在服务器上 |
| at | 点 | at startup / at line 10 | 启动时/第10行 |
| to | 目标/对象 | send to / add A to B | 发送给/把A加到B |
| from | 来源/移出 | read from / remove A from B | 从……读取/从B移除A |
| with | 工具/伴随/具有 | open with / a file with data | 用……打开/带数据的文件 |
| by | 方法/施事者 | by using / created by | 通过使用/由……创建 |
| for | 用途/对象/时长 | used for / for users / for 10 seconds | 用于/面向用户/持续10秒 |
| of | 所属/组成 | a list of items | 项的列表 |
| without | 缺少 | without restarting | 无需重启 |

**介词后接名词性内容：** `before restart` 或 `before restarting`，不接 `before restart to...`这样的随意结构。

## 4. 控制流连接词

| 类型 | 连接词 | 例子 | 解析 |
|---|---|---|---|
| 并列 | and | Save **and** close the file. | 两个动作都执行 |
| 选择 | or | Use a token **or** a key. | 两者选一/根据语境包含或 |
| 转折 | but/however | The request succeeded, **but** the data is empty. | 结果与预期不同 |
| 原因 | because/since | It fails **because** the key is invalid. | 后面给原因 |
| 结果 | so/therefore | The key is invalid, **so** the request fails. | 后面给结果 |
| 条件 | if | **If** the test fails, retry it. | 可能发生的条件 |
| 时间/必然触发 | when | **When** the app starts, it loads the file. | 当该事发生时 |
| 反向条件 | unless | Do not continue **unless** the test passes. | 除非测试通过，否则不继续 |
| 时序 | before/after/then | Save the file **before** you close it. | 先保存，后关闭 |
| 让步 | although/even if | **Even if** it works, test it again. | 条件不改变主句决定 |

### if 和 when 的技术文档差别

- `If the request fails, retry it.`：失败是可能情况，不一定发生。
- `When the request completes, read the response.`：把完成视为正常会发生的时点。

## 5. 否定范围：不要看到 not 就整句都译成否定

| 结构 | 准确理解 |
|---|---|
| not required | 不是必需的/不需要 |
| must not | 严禁，绝对不能 |
| do not have to | 不必，可以不做 |
| not all requests | 并非所有请求 |
| no request | 没有任何请求 |
| cannot be empty | 不能为空 |
| may not work | 可能不起作用，也可能指不允许，需看语境 |

## 6. 逻辑拆解示例

`If the cache is disabled, the client reads the value from the server and stores it in memory before it returns the result.`

| 块 | 内容 | 理解 |
|---|---|---|
| condition | If the cache is disabled | 如果缓存被禁用 |
| actor | the client | 客户端执行后续动作 |
| action 1 | reads the value from the server | 从服务器读取值 |
| action 2 | stores it in memory | 将它存入内存，it = the value |
| order | before it returns the result | 在客户端返回结果之前 |

整句：**如果缓存已禁用，客户端会从服务器读取该值，先将其存入内存，再返回结果。**

## 7. 自测

标记每句的逻辑，并说出动作顺序：

1. If the file exists, open it.
2. When the build completes, check the output.
3. The command failed because the path was invalid.
4. The path was invalid, so the command failed.
5. Save the token before you close the page.
6. Do not delete the key unless you have a backup.
7. The method is slow but reliable.
8. Not all fields are required.

<summary>参考要点</summary>

1. 可能条件；存在则打开。
2. 时间/正常触发；构建完成后检查输出。
3. 结果在前，because 后是原因。
4. 原因在前，so 后是结果。
5. 先保存，后关闭。
6. unless = if not；没有备份就不得删除。
7. 转折：慢，但可靠。
8. 部分否定：并非所有字段都是必需的。
