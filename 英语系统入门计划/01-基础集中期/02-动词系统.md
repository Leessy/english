# 动词系统：句子的运行时

> 动词是技术文档的最高优先级。看到句子时，先解析动词栈，再查其他生词。
>
> 本文用于按需解释；[动词形态表](./09-基础核心速查记忆表.md) 供查询。当前先在轻量小课里熟悉少量组合，不每天抽测整表。

## 1. 五种形式是“接口”，不是五个独立时态

| 形式 | 代码 | 能接在哪里 | 技术例句 | 意思 |
|---|---|---|---|---|
| 原形 | do | modal 后；to 后；祈使句 | **Run** the test. / can **run** | 运行测试 / 能运行 |
| 三单 | does | 一般现在时，he/she/it/单数主语 | The test **runs**. | 测试会运行。 |
| 过去式 | did | 单独作谓语，已经过去 | The test **ran** yesterday. | 测试昨天运行了。 |
| 现在分词 | doing | be + doing；修饰；介词后 | is **running** / a **running** process | 正在运行 / 运行中的进程 |
| 过去分词 | done | have + done；be + done；修饰 | has **run** / a **failed** test | 已经运行 / 失败的测试 |

## 2. 动词栈的固定顺序

```text
[情态 modal] + [完成 have] + [进行 be] + [被动 be] + [实义动词]
```

| 动词栈 | 逐层读法 | 中译 |
|---|---|---|
| loads | 一般行为 + 加载 | 会加载 |
| does not load | 一般行为 + 否定 + 加载 | 不会加载 |
| is loading | 进行 + 加载 | 正在加载 |
| is loaded | 被动/状态 + 加载 | 被加载/已加载 |
| has loaded | 完成 + 加载 | 已经加载了 |
| has been loaded | 完成 + 被动 + 加载 | 已经被加载 |
| must be loaded | 必须 + 被动 + 加载 | 必须被加载 |
| might be loading | 可能 + 进行 + 加载 | 可能正在加载 |
| might have been deleted | 可能 + 已完成 + 被动 + 删除 | 可能已经被删除 |

先识别正在阅读的那一种组合即可；后几行属于逐步扩展内容，不需要前两周全部掌握。

## 3. be 有四个工作

| be 的工作 | 结构 | 例子 | 判断方法 |
|---|---|---|---|
| 系动词 | be + 名词/形容词/位置 | The value is invalid. | 后面在说明主语的性质/身份/位置 |
| 进行助动词 | be + doing | The service is running. | 强调进行过程 |
| 被动助动词 | be + done | The file is deleted. | 主语承受动作 |
| 存在句 | there + be | There is an error. | 引入某个对象 |

### be + done 为什么可能是动作，也可能是状态

| 句子 | 更自然的解释 |
|---|---|
| The file was deleted by the user. | 用户删除了文件（被动动作）。 |
| The file is deleted. | 文件已处于删除状态，也可按上下文译为“文件被删除”。 |
| The connection is closed. | 连接已关闭（结果状态更重要）。 |
| The connection is closed by the server. | 连接由服务器关闭（动作执行者明确）。 |

## 4. do 有两个工作

| 工作 | 例子 | 理解 |
|---|---|---|
| 实义动词“做” | The task does the work. | 任务执行该工作。 |
| 助动词 | The task does not run. | does 承担三单和否定，run 回原形。 |

```text
The command works.             肯定
The command does not work.     否定：does 后 work 回原形
Does the command work?         疑问：does 提前
```

## 5. have 有两个工作

| 工作 | 例子 | 理解 |
|---|---|---|
| 实义动词“有” | The object has three fields. | 该对象有三个字段。 |
| 完成助动词 | The request has failed. | 请求已经失败，结果与现在有关。 |

`has` 后接名词时多半是“有”；后接过去分词时多半是完成时。

## 6. 一般现在时是技术文档的默认时态

技术文档常描述稳定行为、函数功能、规则和结果，因此大量用一般现在时。

| 主语 | 动词 | 例子 |
|---|---|---|
| I/you/we/they/复数 | 原形 | Clients send requests. |
| he/she/it/单数 | -s/-es | The client sends a request. |

API 参考中常看到以三单动词开头的片段：

| 片段 | 脑中补全 | 中译 |
|---|---|---|
| Creates a user. | This method creates a user. | 创建用户。 |
| Returns the current value. | This function returns the current value. | 返回当前值。 |
| Lists all files. | This endpoint lists all files. | 列出所有文件。 |

## 7. 祈使句是技术步骤的默认语气

```text
(You) Open the file.
(You) Set the value to 10.
(You) Run the test again.
```

- 主语 you 被省略。
- 开头动词用原形。
- 否定祈使句用 `Do not`/`Don't + 原形`。
- 文档中的指令通常不需要 `please`。

| 肯定 | 否定 |
|---|---|
| Save the file. | Do not close the file. |
| Use a unique name. | Do not use spaces. |
| Select a region. | Don't select an unavailable region. |

## 8. 必须连同“参数格式”记的动词

| 动词 | 结构 | 例子 | 中译 |
|---|---|---|---|
| allow | allow + 人/系统 + to do | This option allows users to retry. | 该选项允许用户重试。 |
| enable | enable + 人/系统 + to do | The API enables clients to send data. | API 使客户端能发送数据。 |
| require | require + n. / require + 人 + to do | The task requires permission. | 该任务需要权限。 |
| prevent | prevent + 人/物 + from doing | This check prevents users from deleting data. | 该检查防止用户删除数据。 |
| use | use + 物 + to do | Use this key to sign the request. | 使用此密钥对请求签名。 |
| depend | depend on + n./doing | The result depends on the input. | 结果取决于输入。 |
| return | return + 值/对象 | The method returns a list. | 该方法返回列表。 |
| set | set + A + to + B | Set the timeout to 30 seconds. | 将超时时间设为30秒。 |
| add | add + A + to + B | Add the key to the file. | 把密钥添加到文件中。 |
| remove | remove + A + from + B | Remove the item from the list. | 从列表中移除该项。 |

## 9. 自测

说出动词栈的结构和中文意思：

1. `does not return`
2. `is running`
3. `is required`
4. `has failed`
5. `has been deleted`
6. `must be set`
7. `may be omitted`
8. `should not be used`

<details>
<summary>参考要点</summary>

1. do 否定 + 原形；不返回。
2. be + doing；正在运行。
3. be + done，可按被动/形容词状态理解；是必需的/被要求。
4. have + done；已经失败。
5. have + be + done；已经被删除。
6. modal + be + done；必须设置。
7. modal + be + done；可以省略。
8. modal + not + be + done；不应使用。

</details>
