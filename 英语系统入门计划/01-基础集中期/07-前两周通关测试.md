# 基础结构自检题库

> 本题库用于之后查漏补缺，不要求前两周完成。当前先使用轻量阅读小课；想检查某个结构时，只选相应两三题。做后核对解释，不作为开始阅读的门槛。

## A 卷：基础识别

1. 填入 am/is/are：I ___ ready. The file ___ empty. They ___ valid.
2. 填入 do/does：___ it work? The command ___ not change the file.
3. 说出 `he/him/his`、`they/them/their` 的位置差别。
4. 写出 `write`的三单、过去式、现在分词、过去分词。
5. 解释 `Does it work?` 中 work 为什么不加 -s。
6. 区分 `must not` 和 `do not have to`。
7. 区分 `it's` 和 `its`。
8. 说出 `a file → the file` 变化表示什么。

## B 卷：文本类型与完整动词组

对每项标记“陈述/祈使/疑问/名词短语/错误片段”，并圈出完整动词组：

1. Default user settings
2. Create a user.
3. The method creates a user.
4. Does the user exist?
5. User not found
6. The request does not include a key.
7. The key has been deleted.
8. The service might not be running.
9. The value must be set.
10. Data returned by the server

## C 卷：模式识别

对每句说出模式和准确中译：

1. Run the command.
2. The option is optional.
3. The file is created at startup.
4. The function returns a list.
5. There are two modes.
6. It is safe to continue.
7. If the test fails, retry it.
8. To view the log, open this file.
9. The password must not be empty.
10. Data stored in memory is temporary.
11. A token is a string that identifies a user.
12. The API lets you create, update, and delete items.
13. If omitted, the value defaults to zero.
14. Note that this option is deprecated.
15. Permission denied.

## D 卷：未见综合文本

> The client uses a configuration file to connect to the server. By default, the file is loaded from the current directory. You may specify a different path by setting the `configPath` option. If the file is missing, the client returns an error and stops. The file must contain a valid server address, but the `timeout` field is optional. To test the configuration, run `client check`. A successful check does not send any data to the server.

## E 卷：日常、学习与工作迁移

1. 填代词：Lina is my friend. I work with ___. ___ desk is next to ___.
2. 区分：`This is their room.` 和 `This room is theirs.` 中 their/theirs 为什么不能互换？
3. 填 be：I ___ tired yesterday, but they ___ still busy.
4. 解释 look：`Look at the sky.` 和 `The sky looks dark.` 中 look 的工作有什么不同？
5. 写出 go、take、see 的过去式和过去分词。
6. 把 `She studies after dinner.` 改成否定句和一般疑问句。
7. 解释 `I work from home.` 和 `I am working from home this week.` 的差别。
8. 改错：`Did she went home?`；`He didn't called me.`
9. 分别用 there be 和 have 表达：“附近有一家商店”；“我有一个问题”。
10. 用 because 和 so 各表达一次：“我出门晚了，所以错过了公交车。”
11. 区分：`I used to work at night.`、`This key is used to open the door.`、`I am used to working at night.`
12. 准确理解：`Could you send them to me by five? If I receive them today, I will finish the report.`

### A 卷

1. am / is / are。2. Does / does。3. 主格/宾格/形容词性物主代词。4. writes/wrote/writing/written。5. does 已承担三单，后面用原形。6. 禁止/不必。7. it is/has 的缩写 / 它的。8. 首次引入/已知的特定文件。

### B 卷

1. 名词短语，无。2. 祈使，Create。3. 陈述，creates。4. 疑问，Does exist。5. 错误片段，可补 was not found。6. 陈述，does not include。7. 陈述，has been deleted。8. 陈述，might not be running。9. 陈述，must be set。10. 名词短语 + 修饰，returned 不是全句谓语。

### C 卷

1. 祈使。2. 系表状态。3. 被动。4. 一般现在行为。5. there be。6. 形式主语。7. 条件+祈使。8. 目的+祈使。9. 强制+否定系表。10. 分词修饰。11. 定义+定语从句。12. let+并列动词。13. 省略条件+默认行为。14. 注意+弃用状态。15. 错误片段。

### D 卷

1. 说明客户端配置文件的加载、必填内容和测试方法。2. 当前目录。3. 设置 `configPath`选项。4. 返回错误并停止。5. server address 必须有效；timeout 可选。6. 运行 `client check`。7. 不会。8. `is loaded`。9. `may specify`、`must contain`；`is optional` 表可选状态。10. 意思完整、逻辑准确即可。

### E 卷

1. her / Her / mine。2. their 必须放在名词 room 前；theirs 独立作表语，已经包含“他们的房间”。3. was / were。4. 第一处 look 是祈使句中的动作“看”；第二处是系动词“看起来”，dark 描述 sky。5. went/gone，took/taken，saw/seen。6. `She doesn't study after dinner.` / `Does she study after dinner?`。7. 前者表示通常在家办公，后者表示这周的临时安排。8. `Did she go home?` / `He didn't call me.`。9. `There is a shop nearby.` / `I have a question.`。10. `I missed the bus because I left home late.` / `I left home late, so I missed the bus.`。11. 过去常做 / 被用于开门 / 已习惯做。12. “你能在五点前把它们发给我吗？如果今天收到，我就会完成报告。”them 必须从上下文确定所指；by five 表示不晚于五点。
