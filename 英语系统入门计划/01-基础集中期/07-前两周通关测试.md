> 不查教材完成。A-C 卷必须 100%，D 卷至少 85%。不记总分，只记错误类型。

## A 卷：基础反应（100%）

1. 填入 am/is/are：I ___ ready. The file ___ empty. They ___ valid.
2. 填入 do/does：___ it work? The command ___ not change the file.
3. 说出 `he/him/his`、`they/them/their` 的位置差别。
4. 写出 `write`的三单、过去式、现在分词、过去分词。
5. 解释 `Does it work?` 中 work 为什么不加 -s。
6. 区分 `must not` 和 `do not have to`。
7. 区分 `it's` 和 `its`。
8. 说出 `a file → the file` 变化表示什么。

## D 卷：未见综合文本（至少85%）

> The client uses a configuration file to connect to the server. By default, the file is loaded from the current directory. You may specify a different path by setting the `configPath` option. If the file is missing, the client returns an error and stops. The file must contain a valid server address, but the `timeout` field is optional. To test the configuration, run `client check`. A successful check does not send any data to the server.

## 参考答案

<details>
<summary>展开答案</summary>

### A 卷

1. am / is / are。2. Does / does。3. 主格/宾格/形容词性物主代词。4. writes/wrote/writing/written。5. does 已承担三单，后面用原形。6. 禁止/不必。7. it is/has 的缩写 / 它的。8. 首次引入/已知的特定文件。

### B 卷

1. 名词短语，无。2. 祈使，Create。3. 陈述，creates。4. 疑问，Does exist。5. 错误片段，可补 was not found。6. 陈述，does not include。7. 陈述，has been deleted。8. 陈述，might not be running。9. 陈述，must be set。10. 名词短语 + 修饰，returned 不是全句谓语。

### C 卷

1. 祈使。2. 系表状态。3. 被动。4. 一般现在行为。5. there be。6. 形式主语。7. 条件+祈使。8. 目的+祈使。9. 强制+否定系表。10. 分词修饰。11. 定义+定语从句。12. let+并列动词。13. 省略条件+默认行为。14. 注意+弃用状态。15. 错误片段。

### D 卷

1. 说明客户端配置文件的加载、必填内容和测试方法。2. 当前目录。3. 设置 `configPath`选项。4. 返回错误并停止。5. server address 必须有效；timeout 可选。6. 运行 `client check`。7. 不会。8. `is loaded`。9. `may specify`、`must contain`；`is optional` 表可选状态。10. 意思完整、逻辑准确即可。
