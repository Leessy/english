# 基础教材按需使用说明

当前默认路线是 [每次练一句](../../英语考试快速复习站/index.html?view=reading)。词义与结构解释在同一课内；碎片时间只需打开它。十四节阅读小课仅用于基础补漏，不要求已会 `I am` 的人从头重学。

本目录保留为参考库。文件名里的“两周”是旧课程名称，不要求两周学完，也不要求每天随机抽测整张表。

| 需要解决的具体问题 | 按需打开 |
|---|---|
| 一句不明白是谁做什么 | [句子运行机制](./01-英语句子的运行机制.md) |
| 反复看不懂 is doing、has done | [动词系统](./02-动词系统.md) |
| 指代、介词或逻辑总读错 | [功能词与逻辑](./03-功能词与逻辑.md) |
| 正在阅读的文档出现省略或分词修饰 | [技术文档基础语法](./04-技术文档基础语法.md) |
| 想看更多生活例句 | [基础语法多场景精读](./10-基础语法多场景精读.md) |
| 确实需要核对一种词形 | [基础核心速查记忆表](./09-基础核心速查记忆表.md) |

同一种问题在不同句子中反复出现，再集中查对应一小节。查询后，把原句、该处释义和一句解释留在自己的阅读位置；下一次直接重读这句。

读书、听说、写作会逐步加入。当前每次完成一句或一小段的理解就结束，不同时安排多份材料。
