# 英语句子的运行机制

> 传统的“主谓宾”只能解释部分句子。技术文档还大量使用祈使句、被动、名词短语、标题片段、列表项、条件和省略结构。本章的目标是先识别“这是什么类型的代码”，再解析内部。

## 1. 先判断文本类型

| 类型 | 快速特征 | 例子 | 怎样理解 |
|---|---|---|---|
| 陈述句 | 有主语 + 有限动词 | The server returns a response. | 服务器返回响应。 |
| 祈使句 | 以动词原形开头，通常无主语 | Open the file. | （你）打开文件。 |
| 疑问句 | be/助动词/疑问词在前 | Does the command work? | 该命令有效吗？ |
| 被动句 | be + 过去分词 | The file is created. | 文件被创建。 |
| 存在句 | there is/are | There are two options. | 有两个选项。 |
| 形式主语句 | It is + adj. + to do/that... | It is safe to retry. | 重试是安全的。 |
| 条件句 | if/when/unless + 小句 | If the test fails, retry it. | 如果测试失败，请重试。 |
| 名词短语 | 没有有限动词，核心是名词 | Default configuration file | 默认配置文件 |
| 标签/片段 | 按钮、标题、列表项、错误消息 | Access denied | 访问被拒绝 |
| 定义式 | term + be/refer to/colon | A token is a unit of text. | token 是文本单元。 |

**第一步不是强行找主谓宾，而是先问：这是完整句、指令，还是一个标签？**

## 2. 什么是“有限动词”

有限动词是能承担句子时间、人称、否定或语气的动词入口。它不一定是一个词。

| 句子 | 完整动词组 | 不要怎样圈 |
|---|---|---|
| The app **loads** the file. | loads | — |
| The app **does not load** the file. | does not load | 不要只圈 load |
| The file **is loaded** at startup. | is loaded | 不要只圈 loaded |
| The file **has been loaded**. | has been loaded | 不要只圈 been/loaded |
| The value **must be set**. | must be set | 不要只圈 set |
| The service **might not be running**. | might not be running | 不要只圈 running |

### 寻找算法

1. 找动词形式或助动词。
2. 向左扩展，把 modal/have/be/do/not 收进来。
3. 向右找到最后的实义动词。
4. 再问“谁/什么承担这个动词组”。

## 3. 名词短语：技术文档的高密度数据结构

`the new user configuration file` 不是五个并列概念，而是一个整体，核心名词在最右侧：

```text
[the [new] [user] [configuration] file]
                              └─ 核心：文件
                  └─ 什么文件：配置文件
           └─ 谁的/什么对象的配置：用户配置
     └─ 怎样的：新的
```

| 短语 | 核心名词 | 自然译法 |
|---|---|---|
| a local development environment | environment | 本地开发环境 |
| the default request timeout value | value | 默认请求超时值 |
| an open-source command-line tool | tool | 一个开源命令行工具 |
| user access control settings | settings | 用户访问控制设置 |
| server error response data | data | 服务器错误响应数据 |

**读法**：先找最右核心，再向左分层；翻译时再按中文习惯重排。

## 4. 标题、按钮和错误消息为什么“不完整”

技术界面和文档为了简短，经常故意使用片段。不要把它们当成语法错误。

| 文本 | 类型 | 可以在脑中补全为 |
|---|---|---|
| Installation requirements | 名词标题 | Requirements for installation |
| Creating a project | doing 标题 | How to create a project |
| Create project | 祈使式标题/按钮 | Create a project. |
| Access denied | 过去分词错误片段 | Access is denied. |
| File not found | 过去分词错误片段 | The file was not found. |
| Invalid input | 形容词 + 名词 | The input is invalid. |
| No results | no + 名词 | There are no results. |
| Optional | 单词标记 | This step/field is optional. |

## 5. 不只是主谓宾的 12 种必会模式

| # | 模式 | 例子 | 关键理解 |
|---:|---|---|---|
| 1 | 祈使：V + O | Run the command. | 主语 you 被省略 |
| 2 | 系表：S + be + C | The option is required. | required 说明 option |
| 3 | 被动：S + be + done | The token is generated. | S 承受动作 |
| 4 | 现在时行为 | The method returns a list. | 说明稳定行为 |
| 5 | 存在：there be | There are two modes. | 引入新对象 |
| 6 | 形式主语：It is ... to do | It is safe to continue. | 真正内容是 to do |
| 7 | 条件 + 指令 | If it fails, retry. | 先判条件，再执行 |
| 8 | 目的：To do, V... | To continue, click Next. | 前面是目标 |
| 9 | 要求：S + must/should/may | The value must be unique. | 识别要求强度 |
| 10 | 后置修饰：n. + done/doing | data returned by the API | 相当于缩短的从句 |
| 11 | 定义：X is/refers to Y | A hook is a function... | 在建立概念映射 |
| 12 | 列表并列 | Create, test, and deploy. | 三个动词共享主语 |

## 6. 长句不是一次运行，而是多个块

```text
If the request fails, / the client retries the operation / by using the token / returned by the server.
└─ condition        └─ main action             └─ method          └─ modifier
```

- 条件：`If the request fails`（如果请求失败）
- 主干：`the client retries the operation`（客户端重试该操作）
- 方法：`by using the token`（通过使用 token）
- 修饰 token：`returned by the server`（服务器返回的）
- 整句：**如果请求失败，客户端会使用服务器返回的 token 重试该操作。**

## 7. 自测

先标类型，再标完整动词组：

1. `Default network settings`
2. `Restart the service.`
3. `The service does not start automatically.`
4. `The request must be authenticated.`
5. `If the port is unavailable, select another port.`
6. `Data returned by the server`
7. `There is no default value.`
8. `It is not necessary to restart the app.`
9. `Creates a new user.`
10. `Permission denied`

<details>
<summary>参考答案</summary>

1. 名词短语，无有限动词。
2. 祈使句，动词 `Restart`，暗含主语 you。
3. 否定陈述，动词组 `does not start`。
4. 含要求的被动，动词组 `must be authenticated`。
5. 条件 + 祈使；`is`、`select`。
6. 名词短语 + 过去分词后置修饰，`returned` 不是全句谓语。
7. 存在句，`is`。
8. 形式主语，`is`；真正内容是 `to restart`。
9. API 参考说明常见片段，暗含主语为方法/函数。
10. 错误消息片段，可补为 `Permission is denied.`

</details>
