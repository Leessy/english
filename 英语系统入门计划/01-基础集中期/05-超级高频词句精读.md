# 超级高频词句精读

> 本文供扩展示例使用，每次只选一行。当前主线是 [Daily English · 常用句复现](../../每日英语资料/index.html?view=fluency)，不需要同步完成本册；十四节小课仅作基础补漏。
>
> 小课读顺后，可按实际需要选用 [超高频词块手册](../04-词汇与词块/01-超高频词块手册.md)，一次只学一个当前用得上的词块。

## 为什么要单独学超级高频词

- NGSL-S 1.2 用 721 个词覆盖最多约 90% 的非脚本口语，说明最前面的高频词必须优先学。
- 扩展词库中的 800 个带例句词偏书面；与口语最高频层并不充分重合，不适合作为语法入门的第一批精学词。
- 本层优先收入 `be/have/do/get/go/make/take`、代词、助动词和逻辑词，因为它们是理解句子结构的“运行时”。

**使用规则**：每句按“听/读 3 遍→标完整动词组和句式类型→口头翻译→替换一个词复述”学。

---

## 单元 1：代词 + be（谁是什么）

**核心词**：I 我，you 你/你们，he 他，she 她，it 它/这件事，we 我们，they 他们，be 是/处于，am/is/are 是，this 这个，that 那个。

**必掌握词块**：`I am ...`、`This is ...`、`It is ...`、`There is ...`、`be ready for ...`

| 精读句 | 结构与理解 | 准确中译 |
|---|---|---|
| **I am** ready. | S + be + C；ready 说明 I 的状态 | 我准备好了。 |
| **You are** right. | right 是形容词表语 | 你是对的。 |
| **She is** my friend. | my 后必须接名词 | 她是我的朋友。 |
| **It is** a good idea. | it 指一件事；a + 单数名词 | 这是个好主意。 |
| **This is** the problem. | the 表示双方已知的特定问题 | 这就是那个问题。 |
| **There is** a file here. | there be = 某处有某物，here = 这里 | 这里有一个文件。 |

**替换练习**：`I am ready/tired/busy.`；`This is a file/book/test.`

## 单元 2：have + do（拥有与动作）

**核心词**：have 有，has 有（三单），do 做/助动词，does 做/助动词（三单），not 不，what 什么，thing 东西/事情，problem 问题，time 时间，work 工作/奏效，help 帮助，need 需要。

**必掌握词块**：`have a problem`、`have time to do`、`do the work`、`do not know`、`need help with ...`

| 精读句 | 结构与理解 | 准确中译 |
|---|---|---|
| We **have a problem**. | have 是谓语，a problem 是宾语 | 我们遇到了一个问题。 |
| She **has time to help**. | she 后用 has；to help 说明 time 用来做什么 | 她有时间帮忙。 |
| I **do the work** every day. | do 是“做”；every day 表频率 | 我每天做这项工作。 |
| I **do not know**. | do 是助动词，know 用原形 | 我不知道。 |
| **Does** it **work**? | does 已承担三单，work 不加 -s | 它能正常工作吗？ |
| I **need help with** this. | with 引出需要帮助的事 | 我需要别人帮我处理这个。 |

## 单元 3：get/go/come（变化与方向）

**核心词**：get 得到/变得/到达，go 去/运转，come 来/变成，here 这里，there 那里，back 回去，up 向上/完全，down 向下，out 出去，in 在里面，from 从，to 到/向。

**必掌握词块**：`get ready`、`get better`、`go back`、`come from`、`come in`

| 精读句 | 结构与理解 | 准确中译 |
|---|---|---|
| I **get up** at seven. | get up 整体是“起床” | 我七点起床。 |
| Things **get better** with time. | get 是系动词，better 是表语 | 情况会随着时间好转。 |
| We **go to** work by bus. | to 表目标，by 表方式 | 我们坐公交车上班。 |
| Please **go back** and try again. | and 连接两个祈使动作 | 请返回并再试一次。 |
| I **come from** China. | come from = 来自 | 我来自中国。 |
| **Come in** and sit down. | come in/sit down 都是整体词块 | 请进，坐下吧。 |

## 单元 4：make/take/give/put（最常用的操作）

**核心词**：make 制作/使得，take 拿/花费/采取，give 给，put 放，use 使用，keep 保持，let 让，start 开始，stop 停止，try 尝试，again 再一次，way 方法/道路。

**必掌握词块**：`make sure`、`take time`、`give me ...`、`put ... in ...`、`try again`

| 精读句 | 结构与理解 | 准确中译 |
|---|---|---|
| This **makes** the work easy. | make + O + C = 使宾语变得…… | 这会让这项工作变得容易。 |
| It **takes time to learn**. | it 是形式主语；to learn 是真正内容 | 学习需要时间。 |
| Please **give me** an example. | give + 人 + 物 | 请给我一个例子。 |
| **Put** the file **in** this folder. | put + O + 地点 | 把文件放进这个文件夹。 |
| **Use** it this **way** and **try again**. | use 后接宾语 it；this way 表方式 | 按这种方式使用它，然后再试一次。 |
| **Keep** it simple. | keep + O + C = 使它保持某状态 | 保持简单。 |

## 单元 5：can/will/should/would（能力、将来和礼貌）

**核心词**：can 能/可以，could 能/可以（更委婉），will 将/愿意，would 会/愿意（委婉），should 应该，may 可能/可以，might 可能，must 必须，please 请，sure 当然/确定，maybe 也许，possible 可能的。

**必掌握词块**：`Can you ...?`、`Could you please ...?`、`I would like ...`、`You should ...`、`It may ...`

| 精读句 | 结构与理解 | 准确中译 |
|---|---|---|
| **Can you** help me? | 情态动词后用 help 原形 | 你能帮我一下吗？ |
| **Could you please** say that again? | could 在这里表示礼貌，不是过去 | 请你再说一遍，可以吗？ |
| I **will call** you later. | will + 原形表将来 | 我稍后会给你打电话。 |
| I **would like** some water. | would like 比 want 更礼貌 | 我想要一些水。 |
| You **should try** this way. | should + try 原形 | 你应该试试这个方法。 |
| It **may not work**. | not 否定 may；work 仍是原形 | 它可能不起作用。 |

## 单元 6：think/know/mean/understand（思考与理解）

**核心词**：think 认为/思考，know 知道，mean 意思是/意味着，understand 理解，remember 记得，forget 忘记，believe 相信，feel 感觉，like 喜欢/像，right 对的，wrong 错的，idea 想法。

**必掌握词块**：`I think ...`、`I don't know.`、`What does ... mean?`、`Do you understand?`、`feel like doing`

| 精读句 | 结构与理解 | 准确中译 |
|---|---|---|
| **I think** this is right. | think 后接一个省略 that 的宾语从句 | 我认为这是对的。 |
| I **don't know what** to do. | what to do = 该做什么 | 我不知道该做什么。 |
| What **does** this word **mean**? | does 出现后 mean 用原形 | 这个单词是什么意思？ |
| I **understand the idea**, but I don't agree. | but 引出转折 | 我理解这个想法，但我不赞同。 |
| Please **remember to call** me. | remember to do = 记得去做 | 请记得给我打电话。 |
| I **feel like taking** a break. | feel like 后接 doing | 我想休息一下。 |

## 单元 7：say/tell/ask/talk（交流）

**核心词**：say 说（内容），tell 告诉（某人），ask 问/请求，talk 交谈，speak 说话/讲某语言，call 打电话/称为，question 问题，answer 回答，word 单词/话，name 名字，more 更多，slowly 慢慢地。

**必掌握词块**：`say something`、`tell me ...`、`ask a question`、`talk to ... about ...`、`speak more slowly`

| 精读句 | 结构与理解 | 准确中译 |
|---|---|---|
| Please **say your name** again. | say 后接说出的内容 | 请再说一遍你的名字。 |
| Please **tell me the answer**. | tell + 人 + 内容 | 请告诉我答案。 |
| May I **ask a question**? | may I ...? 是礼貌请求许可 | 我可以问个问题吗？ |
| We need to **talk about** this problem. | talk about = 谈论 | 我们需要谈谈这个问题。 |
| Could you **speak more slowly**? | more slowly = 更慢地 | 你能说慢一点吗？ |
| I will **call you back**. | call back = 回电话 | 我会给你回电话。 |

## 单元 8：but/because/if/when（句子逻辑）

**核心词**：and 并且，but 但是，or 或者，so 所以，because 因为，if 如果，when 当……时，before 在……之前，after 在……之后，then 然后，also 也，only 只。

**必掌握词块**：`A and B`、`..., but ...`、`because of ...`、`if necessary`、`before doing`

| 精读句 | 结构与理解 | 准确中译 |
|---|---|---|
| It is simple **and** useful. | and 连接同级形容词 | 它既简单又实用。 |
| I tried, **but** it did not work. | but 后是与预期相反的结果 | 我试过了，但它没有起作用。 |
| We stopped **because** it was late. | because 后接完整句子 | 因为时间已经很晚，所以我们停了下来。 |
| **If** you need help, call me. | if 引出条件；祈使句 call 用原形 | 如果你需要帮助，就给我打电话。 |
| Save the file **before** you close it. | it 指代 the file | 关闭文件之前先保存。 |
| Finish this, **then** start the next one. | then 标记操作顺序 | 做完这个，然后再开始下一个。 |

## 单元 9：now/already/still/often（时间和频率）

**核心词**：now 现在，today 今天，later 稍后，already 已经，still 仍然，yet 还/尚未，always 总是，often 经常，sometimes 有时，never 从不，first 首先/第一，last 上一个/最后。

**必掌握词块**：`right now`、`not yet`、`still working`、`already done`、`from time to time`

| 精读句 | 结构与理解 | 准确中译 |
|---|---|---|
| I am busy **right now**. | right now 强调“就在此刻” | 我现在正忙。 |
| I have **already finished** it. | have + done；already 常放在两者中间 | 我已经把它做完了。 |
| It is **still working**. | still = 之前如此，现在仍如此 | 它还在运行。 |
| I haven't finished **yet**. | yet 在否定完成时中常放句末 | 我还没做完。 |
| We **often use** this method. | 频率副词常放在实义动词前 | 我们经常使用这种方法。 |
| **First** read it; **then** try it. | first/then 组织步骤 | 先读一遍，然后试一下。 |

## 单元 10：good/big/same/different（常用描述）

**核心词**：good 好的，bad 坏的，big 大的，small 小的，new 新的，old 旧的/年老的，same 相同的，different 不同的，easy 容易的，hard 困难的/努力地，important 重要的，ready 准备好的。

**必掌握词块**：`be good at`、`the same as`、`different from`、`easy to use`、`It is important to ...`

| 精读句 | 结构与理解 | 准确中译 |
|---|---|---|
| She is **good at** English. | at 是介词，后接名词或 doing | 她擅长英语。 |
| This file is **the same as** that one. | one 代替已出现的单数名词 file | 这个文件和那个相同。 |
| My result is **different from** yours. | yours = your result | 我的结果和你的不同。 |
| The new tool is **easy to use**. | to use 说明“容易做什么” | 这个新工具很容易使用。 |
| It is **hard to find** the problem. | it 是形式主语 | 这个问题很难找出来。 |
| It is **important to be ready**. | important 说明 to be ready 这件事 | 做好准备很重要。 |

## 本文自检

以下是可选自检，不要求一次完成。初期优先检查能否读懂新句中的主干、否定和条件。

1. 看到 I/he/they 能选择对应的 am/is/are，不限时。
2. 能解释 `Does it work?` 中 work 为什么不加 -s。
3. 能用 get 说“起床”和“变好”。
4. 能说出 `Can you help me?`、`Could you say that again?`、`What does this mean?`。
5. 能分辨 `I finished it.` 和 `I have finished it.` 的基本差别。
6. 能用 but/because/if 各造一句。
7. 从本文选几句读懂，再试一个替换了人物或对象的新句；允许核对词义。
