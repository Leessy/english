# 发音、听力与朗读基础

> 目标是听得出、说得清、能保持节奏，不是消除口音。先选择美式或英式作为主要模仿来源，理解另一种常见发音即可。

## 1. 为什么认识单词仍然听不懂

书面单词之间有空格，真实语流没有清晰的逐词停顿。听力困难通常同时来自：

- 不熟悉单词的声音，只记住了拼写和中文。
- 功能词会弱读，例如 `to`、`for`、`and` 常常很轻。
- 相邻声音会连接，词尾辅音接下一个元音。
- 说话人重读关键词，把已知信息说得更轻。
- 大脑还不能实时按意群处理，只能一个词一个词翻译。

## 2. 先掌握这五件事

| 项目 | 理解 | 例子 |
|---|---|---|
| 音节 | 一个词有几个节奏单位 | `con-FIG-ure` 有三个音节 |
| 单词重音 | 多音节词中一个音节更突出 | `re-QUIRE`、`AVAIL-able` |
| 句子重音 | 名词、主要动词、形容词等通常更突出 | `CHECK the FILE.` |
| 弱读 | 功能词经常缩短变轻 | `I need to CHECK it.` 中 `to` 很轻 |
| 意群 | 按意义成组，而不是每个词都停 | `If it fails / check the log / and try again.` |

音标用于查声音，不必先背完整音标表。每学一个核心词，至少同时确认重音、听一次词典音频并大声说一次。

## 3. 10 分钟精听跟读法

选 20-60 秒、有文本、第一遍能懂大半的音频：

1. 不看文本听一遍，说出主题。
2. 看文本听一遍，划分意群并圈重读词。
3. 查最多 3-5 个真正阻塞理解的词。
4. 每句暂停，先听后模仿，不同时抢读。
5. 跟着声音同步读 2-3 遍。
6. 录下自己，比较漏词、重音和停顿。
7. 合上文本再听，确认是否比第一遍清楚。

同一段连续练 3 天通常比每天换新音频更有效。

## 4. 最先练的语法声音

| 形式 | 注意点 | 例句 |
|---|---|---|
| 缩写 | `I'm`、`it's`、`don't`、`can't` 要整体听 | `It isn't ready.` |
| 复数/三单 -s | 可能读 /s/、/z/、/ɪz/ | `works`、`runs`、`uses` |
| 过去式 -ed | 可能读 /t/、/d/、/ɪd/ | `worked`、`called`、`needed` |
| 弱读 to | 常比独立读音短而轻 | `I want to try.` |
| 辅音接元音 | 词边界听起来会连接 | `turn_it_on`、`check_it` |

具体动词形式见 [`../05-速查与资源/01-动词变形与代词速查.md`](../05-速查与资源/01-动词变形与代词速查.md)。

## 5. 朗读验收

- 能先理解再朗读，不用声音掩盖不懂的句子。
- 能按意群停顿，不在冠词和名词、助动词和动词之间乱停。
- 能突出动作、对象、否定和条件等关键信息。
- 漏音或读错时能回到词典音频确认，而不是只按拼写猜。
- 一周后重新录同一段，能明显更连贯。

推荐从 [VOA Learning English](https://learningenglish.voanews.com/) 和 [British Council Listening](https://learnenglish.britishcouncil.org/free-resources/listening) 选择带文本的 A1-A2 材料。
