# 两周技术文档精读

> 以下文本是为零基础重写的受控技术英语，不依赖某个特定产品。每篇只引入少量新结构，但会重复以前的词和语法。

## 精读协议

1. 先不看分析，读英文两遍。
2. 标出文本类型和完整动词组。
3. 先说每句主要操作，再处理修饰成分。
4. 对照分析，纠正错误类型。
5. 遮住英文，根据中文用简单英文复述。

---

## 第 1 天：这是什么

> This is a configuration file. It is small, but it is important. The file is in the project folder. It has three settings.

| 块 | 解析 | 中译 |
|---|---|---|
| This **is** a configuration file. | be + 名词；定义/分类 | 这是一个配置文件。 |
| It **is** small, but it **is** important. | it = file；but 转折；两个 be + adj. | 它很小，但很重要。 |
| The file **is** in the project folder. | be + 介词短语表位置 | 该文件位于项目文件夹中。 |
| It **has** three settings. | has = 有，不是完成时 | 它有三项设置。 |

**必会词块**：`This is ...`、`be important`、`in the folder`、`have three settings`。

## 第 2 天：读标题和界面文本

> Project settings  
> Default file location  
> Create project  
> Invalid project name  
> No files found

| 文本 | 类型 | 补全与理解 |
|---|---|---|
| Project settings | 名词短语 | 项目设置；settings 是核心 |
| Default file location | 名词短语 | 默认文件位置；location 是核心 |
| Create project | 祈使/按钮文本 | 创建项目 |
| Invalid project name | 形容词 + 名词短语 | 项目名称无效 |
| No files found | 错误片段 | No files were found. 未找到文件。 |

**必会能力**：看到没有完整谓语的文本，先判断是否为标题、按钮或错误片段。

## 第 3 天：动词组不只是最后一个词

> The service is running. It does not use the old file. The new file has been loaded. You can now start the test.

| 完整动词组 | 栈 | 中译 |
|---|---|---|
| **is running** | be + doing，进行 | 服务正在运行。 |
| **does not use** | do + not + 原形，否定 | 它不使用旧文件。 |
| **has been loaded** | have + be + done，完成被动 | 新文件已加载。 |
| **can start** | modal + 原形 | 你现在可以开始测试。 |

**复述**：The service is running. It uses the new file. You can start the test.

## 第 4 天：API 做什么

> The `createUser` method creates a user. It takes a name and an email address. It returns the new user ID. The method does not save a password.

| 句子 | 谓语 | 语法点 | 中译 |
|---|---|---|---|
| The method **creates** a user. | creates | method 是单数，加 -s | 该方法创建一个用户。 |
| It **takes** a name and an email address. | takes | take = 接收参数 | 它接收名称和邮箱地址。 |
| It **returns** the new user ID. | returns | return = 返回 | 它返回新用户 ID。 |
| The method **does not save** a password. | does not save | does 出现后 save 回原形 | 该方法不保存密码。 |

**API 动词签名**：`takes input`、`returns output`、`creates an object`、`does not modify data`。

## 第 5 天：执行一组步骤

> To create a project, follow these steps:
>
> 1. Open the app.
> 2. Select **New project**.
> 3. Enter a project name.
> 4. Click **Create**.

| 结构 | 理解 |
|---|---|
| To create a project | 目的：要创建项目 |
| follow these steps | 祈使句，暗含 you |
| Open / Select / Enter / Click | 每个列表项用原形动词开头，保持平行 |

**中译**：要创建项目，请按以下步骤操作：打开应用；选择“新建项目”；输入项目名称；单击“创建”。

## 第 6 天：否定、疑问和错误排查

> The command does not work. Does the file exist? Is the path correct? If the file does not exist, create it. Do not use an empty path.

| 句子 | 类型 | 中译 |
|---|---|---|
| The command **does not work**. | 一般现在否定 | 该命令不起作用。 |
| **Does** the file **exist**? | do 疑问；exist 原形 | 该文件存在吗？ |
| **Is** the path correct? | be 疑问 | 路径正确吗？ |
| If the file **does not exist**, **create** it. | 条件 + 祈使 | 如果文件不存在，请创建它。 |
| **Do not use** an empty path. | 否定祈使 | 不要使用空路径。 |

## 第 7 天：主动、被动和状态

> The application creates a log file. The file is stored in the data folder. It is closed when the application stops. Old log files are deleted after seven days.

| 句子 | 主动/被动 | 执行者 | 中译 |
|---|---|---|---|
| The application **creates** a log file. | 主动 | application | 应用创建日志文件。 |
| The file **is stored** in the data folder. | 被动/结果 | 不重要/未写 | 该文件存储在数据文件夹中。 |
| It **is closed** when the application stops. | 被动 | 按语义是 application | 应用停止时，该文件会被关闭。 |
| Old log files **are deleted** after seven days. | 被动 | 系统/未写 | 旧日志文件会在7天后被删除。 |

## 第 8 天：强制、建议和可选

> Each request must include an API key. You should store the key in a secure location. You may use a different key for each app. The key must not be shared publicly.

| 结构 | 等级 | 中译 |
|---|---|---|
| must include | 强制 | 每个请求必须包含 API 密钥。 |
| should store | 推荐 | 应将密钥存储在安全位置。 |
| may use | 可选 | 可以为每个应用使用不同的密钥。 |
| must not be shared | 强制禁止 + 被动 | 不得公开共享该密钥。 |

**检查**：`must not` 是禁止；`does not have to` 才是不必。

## 第 9 天：条件、触发和反向条件

> If the request fails, check the error code. When the server returns code 401, create a new token. Do not retry the request unless the token is valid.

| 连接词 | 块 | 逻辑 |
|---|---|---|
| if | request fails | 失败是可能情况；发生后检查错误码 |
| when | server returns 401 | 收到401时创建新 token |
| unless | token is valid | token 无效时不得重试 |

**中译**：如果请求失败，请检查错误码。当服务器返回401时，请创建新 token。除非 token 有效，否则不要重试请求。

## 第 10 天：目的、用途和方法

> Use the `list` command to view all users. The `delete` command is used for removing a user. You can filter the list by adding a name. To save the output, add `--output file.txt`.

| 结构 | 功能 | 中译 |
|---|---|---|
| use X to do | 使用工具实现目的 | 使用 `list` 命令查看所有用户。 |
| be used for doing | 说明用途 | `delete` 命令用于删除用户。 |
| by doing | 说明方法 | 可通过添加名称来筛选列表。 |
| To do, ... | 目的在前 | 要保存输出，请添加 `--output file.txt`。 |

## 第 11 天：分词把从句压缩成修饰块

> The running process uses data stored in memory. Data returned by the API is added to the selected file. Failed requests are written to the error log.

| 压缩块 | 展开 | 中译 |
|---|---|---|
| running process | process that is running | 运行中的进程 |
| data stored in memory | data that is stored in memory | 存储在内存中的数据 |
| Data returned by the API | Data that is returned by the API | API 返回的数据 |
| selected file | file that is selected | 选中的文件 |
| Failed requests | requests that have failed | 失败的请求 |
| are written | be + done，全句谓语 | 会被写入 |

**关键**：`returned/stored/selected/failed` 可能只修饰名词；不要把它们全部当成句子谓语。

## 第 12 天：定义、列表和并列

> A workspace is a folder that contains project files. It lets you create projects, manage settings, and view logs. A workspace contains the following items:
>
> - A configuration file
> - A data folder
> - A log folder

| 结构 | 解析 |
|---|---|
| A workspace is a folder | 用 be 建立定义 |
| that contains project files | that 从句修饰 folder |
| lets you create/manage/view | let + 人 + 原形；三个动词并列 |
| the following items: | 冒号引出列表 |
| 三个列表项 | 共享 `A workspace contains` |

**中译**：workspace 是一个包含项目文件的文件夹。你可在其中创建项目、管理设置和查看日志。workspace 包含配置文件、数据文件夹和日志文件夹。

## 第 13 天：默认配置、注意和功能状态

> By default, logging is enabled and the log level is set to `info`. If omitted, the file path defaults to the current folder. Note that the old `debugMode` option is deprecated. Use `logLevel` instead.

| 模板 | 理解 |
|---|---|
| By default | 默认情况下 |
| is enabled | 被动/状态：已启用 |
| is set to | 被设为 |
| If omitted | 如果未提供该值 |
| defaults to | 默认为 |
| Note that | 引出需注意的信息 |
| is deprecated | 已弃用，不等于已删除 |
| instead | 改用另一项 |

## 第 14 天：综合文档

> To connect your app to the service, create an API key in the console. The key is generated when you select **Create key**. Each request must include the generated key in the `Authorization` header. If the key is missing or invalid, the server returns code 401 and rejects the request. By default, a key remains valid until it is deleted. Do not share the key or store it in a public file.

### 自己先分块

```text
To connect your app to the service, / create an API key / in the console.
The key / is generated / when you select Create key.
Each request / must include / the generated key / in the Authorization header.
If the key is missing or invalid, / the server / returns code 401 / and rejects the request.
By default, / a key / remains valid / until it is deleted.
Do not share the key / or store it in a public file.
```

### 结构清单

1. `To connect...`：目的。
2. `create...`：祈使句。
3. `is generated`：被动。
4. `when...`：触发时点。
5. `must include`：强制要求。
6. `generated key`：过去分词修饰。
7. `If...`：条件。
8. `returns ... and rejects...`：两个并列动作。
9. `By default`：默认行为。
10. `until it is deleted`：持续终点 + 被动。
11. `Do not share ... or store ...`：否定祈使 + 并列。

### 准确中译

要将你的应用连接到该服务，请在控制台中创建 API 密钥。选择“创建密钥”时，系统会生成密钥。每个请求都必须在 `Authorization` 请求头中包含生成的密钥。如果密钥缺失或无效，服务器会返回401并拒绝请求。默认情况下，密钥在被删除前一直有效。不要共享密钥，也不要将其存储在公开文件中。
