# 日常交流基础

> 口语不需等学完所有语法再开始。使用已经掌握的动词和词块，每次只替换一个插槽。

## 1. 最小生存词块

| 功能 | 句型 | 替换插槽 |
|---|---|---|
| 介绍 | I'm ___. / I work in ___. | name / city / software / sales |
| 需要 | I need ___. / I need to ___. | help / more time / check it |
| 想要 | I'd like ___. / I'd like to ___. | water / try again |
| 请求 | Could you ___? | help me / repeat that / speak slowly |
| 确认 | Do you mean ___? | this file / tomorrow / the new version |
| 没听懂 | I didn't catch that. | 整句直接调用 |
| 询问词义 | What does ___ mean? | this word / deprecated / optional |
| 表达看法 | I think ___. | it works / this is better |
| 委婉异议 | I'm not sure I agree. | 整句调用 |
| 检查 | Let me check. | 整句调用 |
| 回应 | That makes sense. / Sounds good. | 整句调用 |
| 结束 | Thanks for your time. | 整句调用 |

## 2. 每天 5 分钟训练

1. 选一个场景：工作、问路、购物、求助、讨论问题。
2. 从上表选5个词块。
3. 先读两遍，再不看文本说一遍。
4. 替换插槽再说一遍。
5. 只修正影响理解的错误，不追求复杂句。

## 3. 技术交流小对话

> A: Does the command work?  
> B: No, it returns an error.  
> A: What does the error say?  
> B: It says, "Permission denied."  
> A: Let me check the settings.  
> B: Thanks. Could you show me how to fix it?

**可复用骨架**：是否正常→现象→错误内容→检查→请求演示。

## 4. 达标

- 能不看文本说出上表12类功能中的至尐8类。
- 能对一个简单技术问题进行6轮问答。
- 听不懂时能主动请对方重复、降速或解释关键词。
