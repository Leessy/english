# 听力与口语持续训练

## 1. 两类听力必须分开

| 类型 | 目的 | 材料和做法 |
|---|---|---|
| 精听 | 补声音、词块和语法的缺口 | 30 秒至 2 分钟、有文本、重复多遍 |
| 泛听 | 适应语速并享受内容 | 大意能懂、无需频繁暂停的长一点材料 |

完全听不懂的内容可以偶尔接触，但不能作为主要训练。长期播放听不懂的音频不等于获得了可理解输入。

## 2. 一周循环

| 日 | 输入 | 输出 |
|---|---|---|
| 一 | 选一段音频，盲听、看稿、查阻塞词 | 逐句模仿 |
| 二 | 不看稿再听，核对文本 | 用 5 句复述 |
| 三 | 跟读并录音 | 回答 3 个相关问题 |
| 四 | 换同主题第二段 | 比较两段共同词块 |
| 五 | 精听第二段 | 做 2 分钟口述 |
| 六 | 两段连听 | 模拟对话或写短总结 |
| 日 | 轻松泛听 | 记录下周一个声音问题 |

## 3. 口语不是从自由聊天开始

按可控程度逐级增加：

1. 替换句型：`I need to check the file.` → `We need to update the app.`
2. 看关键词复述已学文章。
3. 回答可预期问题，每题 2-4 句。
4. 角色扮演：请求、确认、澄清、报告问题。
5. 说明真实工作步骤或当天经历。
6. 与真人或语音工具进行无法完全预测的对话。

## 4. 卡住时的修复工具

| 功能 | 表达 |
|---|---|
| 请求重复 | `Could you say that again?` |
| 请求说慢 | `Could you speak a little more slowly?` |
| 确认理解 | `Do you mean ...?` / `So, I need to ..., right?` |
| 给自己时间 | `Let me think.` / `Let me check.` |
| 不确定 | `I'm not sure, but I think ...` |
| 换简单说法 | `In other words, ...` / `What I mean is ...` |
| 不知道词 | `I don't know the exact word, but it is used to ...` |

## 5. 反馈优先级

一次录音或对话不要修所有问题。依次处理：

1. 对方是否理解了目的和关键信息。
2. 否定、时间、条件是否说反。
3. 高频动词和词块是否用对。
4. 影响理解的发音和停顿。
5. 不影响理解的小语法或口音差异。

每周选择一个反复问题，例如三单 -s、过去时间或单词重音，在多次输出中集中修复。
