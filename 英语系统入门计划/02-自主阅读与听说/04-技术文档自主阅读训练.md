# 技术文档自主阅读训练

## 第 1 周：安装与前置要求

每天找一小节 Quickstart/Getting started，只读以下部分：Prerequisites、Install、Verify。

```text
Document:
Goal:
Required software:
Required account/permission:
Install action:
Verification action:
Success result:
New verb patterns:
```

**达标**：能按顺序用中文说明安装过程，并识别所有祈使句。

## 第 2 周：配置与命令行

每天选一个配置项或命令，填写：

| 字段 | 内容 |
|---|---|
| 参数/选项名 |  |

| 有效值/范围 |  |
| 省略后的行为 |  |
| 生效时间 |  |
| 配置例子 |  |

**达标**：看到 `required`、`optional`、`defaults to`、`if omitted`、`takes effect`能立即解释。

## 第 3 周：API 参考

每天只读一个方法/端点：

```text
Name:
What it does:
HTTP method / call form:
Required input:
Optional input:
Return value:
Possible errors:
One example:
```

必须标出以下动词：`creates`、`gets`、`lists`、`updates`、`deletes`、`accepts`、`returns`、`throws`、`requires`。

**达标**：不翻译每个参数名，仍能说明方法的 input 和 output。
