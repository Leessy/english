# 自主阅读与听说路线

> 第 3 周起可以在控制难度下使用本目录；完成 8 周基础集中期后，它成为长期主线。目标不是不用工具，而是知道何时猜、何时查、怎样核验和怎样把新知识变成自己的能力。

## 1. 每周四线循环

| 学习线 | 阅读方向 | 听说方向 | 每周产出 |
|---|---|---|---|
| 意义输入 | 分级文章、工作窄读 | 带文本音频、同主题泛听 | 5 次输入记录 |
| 意义输出 | 英文摘要、短消息 | 复述、角色扮演、真实提问 | 3 次口述、2 次短写 |
| 语言聚焦 | 长句、词块、领域词 | 重音、连读、一个发音问题 | 10-30 个按需项目 |
| 熟练度 | 重读已懂文章 | 重听、跟读、限时复述 | 一份前后对比 |

## 2. 阅读两遍法

### 第一遍：不查词，只取结构和主线

1. 看标题，判断是故事、教程、操作、参考还是排错。
2. 圈标题和列表，不把片段强行当完整句。
3. 圈祈使动词和完整动词组。
4. 标出 if/when/unless/but/because/therefore/before/after。
5. 用一句话说出“谁遇到什么、做了什么、结果怎样”或“文档让我做什么”。

### 第二遍：只查阻塞词并核验

优先查：谓语核心、否定或要求强度、标题定义、重复领域词，以及不查就无法理解结果的词。

暂不查：产品名、变量名、文件名、可以从例子猜出的词，以及只增加细节但不改变主线的形容词。

如果每 100 词需要查十多个普通词，材料很可能过难。把它留作精读，另选更简单的内容做泛读。

## 3. 常见技术文档的提问模板

| 文档 | 必问问题 |
|---|---|
| Tutorial / Quickstart | 最终得到什么？步骤顺序是什么？需要哪些前提？ |
| How-to | 什么条件下做？具体操作是什么？成功标志是什么？ |
| Reference | 对象是什么？接收什么？返回什么？默认值和限制是什么？ |
| Troubleshooting | 现象是什么？可能原因是什么？怎样确认和修复？ |
| Release / Migration | 什么发生了变化？谁受影响？必须采取什么动作？风险是什么？ |

## 5. 自主阶段的升级条件

- A2 材料大部分无需查词即可理解时，加入少量 B1 精读。
- 300-600 词入门文档能说出目的、前提、步骤、默认行为和风险时，开始阅读同领域更完整页面。
- 已精读音频可以在不看文本时听懂主线，并能用简单英语复述时，再提高语速或长度。
- 能自己发现薄弱点、选择对应练习并在一周后复测，才算真正形成自主学习闭环。
