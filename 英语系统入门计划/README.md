# 英语系统入门计划

当前目标：读懂简短工作消息、日常说明和熟悉领域的入门文档，逐渐减少对整句翻译的依赖。

**当前默认：打开 [快速复习站 · 每次练一句](../英语考试快速复习站/index.html?view=reading)。** 适合认识常见词和 `am / is / are`，但连句理解不熟练的人。12 组常用结构，每组从短句加一层到组合句；词义、断句和译文同页可查，并记住练习位置。

学习方法与句式速览：[从熟词到复杂句](./00-轻量阅读入门/03-从熟词到复杂句.md)。原来的 [十四节阅读小课](./00-轻量阅读入门/01-十四节阅读小课.md) 改为基础补漏，不再要求从 `I am` 重学。

## 每次只做三件事

1. 用 2 分钟回忆上次的一句英文。忘记时直接看同页解释。
2. 用 6 分钟读今天一层例句，找出完整动作、对象和从句关系。
3. 用 2 分钟试同页的换句题，再核对解释；隔天先复习。

只有 3 分钟时，只读懂一句并说出意思，就可以结束。中断几天后，从上次的那一句继续；不补课，不从头再来。

## 先形成句子的直觉

先练 `don’t need to`、`has been saved`、`the file you sent`、`I think (that)…` 等完整词块和小句，再逐步增加词汇。同一结构同时配日常和工作例句，先求理解，逐渐求熟练。

会看懂一句、能自己说出一句、能迅速听懂一句，是不同程度的掌握。当前先练阅读理解；不要求先背完代词变格、50 个动词五形态或 800 个单词。

12 组是顺序，不是 12 天期限。每组可分几次学习，忙时只读一层。先用 4–8 周试行，再按实际阅读表现调整；这不是达到某个英语等级的时间保证。

## 下一步

每四组有一次整段阅读；能说明主线和限制，就尝试熟悉产品的一小段说明。也可用 [从短句到真实资料](./00-轻量阅读入门/02-从短句到真实资料.md) 降低难度，不必等全部学完。
