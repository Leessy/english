# 英语系统入门计划

当前目标：读懂简短工作消息、日常说明和熟悉领域的入门文档，逐渐减少对整句翻译的依赖。

**当前默认：打开 [Daily English · 每日英语资料](../每日英语资料/index.html)。** 如果基础例句大多能懂，只是反应慢、忘词或不熟悉变形，就先用“常用句复现”和“短文泛读”，不必从头学语法。

现在有 108 条常用句复现、8 篇短文及 3 篇约 600 词的分章原创故事，按“生活工作先练 → 文档长句随后 → 压缩混合后学”安排。“核心词与词块”汇总 144 个通用与生活核心条目和 28 个优先词块，均在多个例句中复现。点词看词形，点“译”原地看整句；结构卡住时再查原 12 组分层解析。音色与语速可在顶部“朗读设置”调整。选词依据、内容范围与 Mac 试听说明见[每日英语资料使用说明](../每日英语资料/README.md)。

经常分不清过去式和过去分词时，用[动词形态复现](../每日英语资料/index.html?view=verbs)：41 个重点动词，每项先学词形至少有 3 条不同语境；新增 225 条生活、工作和 IT 例句。每次只选一个动词的一种形态，不用一次背完五形态表。特殊用法标明后学。

学习方法与句式速览：[从熟词到复杂句](./00-轻量阅读入门/03-从熟词到复杂句.md)。原来的 [十四节阅读小课](./00-轻量阅读入门/01-十四节阅读小课.md) 改为基础补漏，不再要求从 `I am` 重学。

## 每次只做三件事

1. 用 2 分钟回忆上次的一句英文。忘记时直接看同页解释。
2. 用 6 分钟读 3–6 条同结构变式，或一小段短文；需要时直接点词。
3. 合上词义提示再读一次，只收藏今天反复卡住的 1–3 项；隔天先复习原句。

只有 3 分钟时，只读懂一句并说出意思，就可以结束。中断几天后，从上次的那一句继续；不补课，不从头再来。

## 先形成句子的直觉

先练 `don’t need to`、`has been saved`、`the file you sent`、`I think (that)…` 等完整词块和小句，再逐步增加词汇。同一结构同时配日常和工作例句，先求理解，逐渐求熟练。

会看懂一句、能自己说出一句、能迅速听懂一句，是不同程度的掌握。当前先练阅读理解；不要求先背完代词变格、50 个动词五形态或 800 个单词。

12 组用于找结构缺口，不是必须从头重学的 12 天任务。当前先反复接触已能理解的句子，再增加短文；没有固定天数或词汇数字能保证无障碍阅读。

## 下一步

读完一篇短文，能说明主线和限制，就尝试相近主题的另一篇，再读熟悉产品的 3–5 句说明。每句都得停下来时，先只读一段；也可用 [从短句到真实资料](./00-轻量阅读入门/02-从短句到真实资料.md) 降低难度。
