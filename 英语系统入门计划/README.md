# 英语系统入门计划

这是一个面向英语基础薄弱成年人的系统课程。最终目标不是完成一套资料，而是获得三种可持续能力：

1. 看懂基础日常英语、工作信息和入门技术文档。
2. 用简单但正确的英语完成问候、提问、确认、说明问题和表达需要。
3. 遇到新词、新结构和新领域时，能使用上下文、词典和语法工具继续自学。

## 先回答最重要的问题：精记 800 词够不够

**够开始，不够结束。** 800 个真正会理解、会听辨、会放进句子的高价值词，比匆忙扫过几千词更有用；它们可以支撑本项目的受控精读和基本表达。但真实日常内容和技术文档还包含大量一般词、固定搭配和领域词，不能靠一个“800”数字自动解决。

本项目因此不把所有词放在同一优先级：

| 层级 | 学习目标 | 内容 | 掌握要求 |
|---|---|---|---|
| L0 结构核心 | 看懂句子骨架 | 代词、be、助动词、介词、连接词、常用动词 | 3 秒识别，能替换造句 |
| L1 超高频词块 | 立即理解和表达 | `I need to`、`there is`、`make sure`、`depends on` 等 | 听、说、读都能快速调用 |
| L2 高频扩展 | 阅读日常和工作内容 | 常见名词、动词、形容词及搭配 | 在例句中理解，逐步主动使用 |
| L3 识别词与领域词 | 扩大真实阅读范围 | 书面词、低频词、专业术语 | 先认大意，需要时再精学 |

1. 先读 [`00-学习路线/01-系统学习总路线.md`](./00-学习路线/01-系统学习总路线.md)。
2. 按 [`00-学习路线/02-基础集中期八周计划.md`](./00-学习路线/02-基础集中期八周计划.md) 学习。

5. 第 8 周完成验收后，进入 [`02-自主阅读与听说/01-自主学习路线.md`](./02-自主阅读与听说/01-自主学习路线.md) 的长期循环。

## 课程的五条底线

- **理解先于数量**：一个词要连同词性、常见搭配和例句学习。
- **句块先于逐字翻译**：把 `be able to`、`as a result` 当整体处理。
- **输入必须可理解**：材料太难时降级，不把不停查词误当阅读。
- **每次学习必须回忆**：合上答案再说、再写、再解析。
- **四项能力不能长期缺席**：阅读、听力、口语、写作都用简单材料持续练。

“完全掌握基础”不是知道所有语法名称，而是能稳定解析常见结构、理解高频表达，并且知道自己卡在词义、句法、声音还是领域知识。达到这一点后，工作中的英语接触才会从噪音变成持续输入。
