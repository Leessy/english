# 阅读进展与复习记录

## 1. 先看理解表现

| 观察点 | 当前要求 |
|---|---|
| 主干 | 能说出谁/什么处于什么状态，或谁做什么 |
| 否定和条件 | 对照后能修正，不把不允许看成允许，不把先后读反 |
| 高频形式 | 在句中认出 uses/use、is working、is saved 等，不要求整表默写 |
| 新句迁移 | 熟悉结构换了对象或时间，还能理解 |
| 查词 | 允许看同页词卡或词典，查后能回到原句 |

默认读句训练以同页换句题和每四组的短段为检验：能说明主线、核对后弄清否定和条件，就可以继续。没答对的一句在下一次开头再试；“已练”不是掌握率。补漏小课的三问也不要求全对才能开始阅读。

## 2. 区分三种掌握

1. **识别**：看到 `doesn't work`，能读成“不起作用”。先达成这一层。
2. **迁移**：`The app doesn't work.` 换成 `The key doesn't work.` 仍能理解。key 是钥匙。
3. **调用**：需要表达时能自己说出来，再进一步听辨它。

阅读入门以识别和迁移为主，主动拼写与流利输出后续逐步补齐。

## 3. 重复安排

每次开头回忆上一课留下的一句；学约三课后用一次时间复习旧句；隔一周再试少量已经学过的句子。具体间隔可调整，不必维护复杂日期表。

先遮住答案理解，再核对；记不住就看解释。反复漏掉的 not、before 等用成对例句复习，避免只记中文释义。

## 4. 一行进度

`下次：第 __ 课的 __；先复习：____。`

每周有空时再问三件事：读懂了哪一句新句子？最常卡在哪里？下一次能否只修这一个问题？

## 5. 开始外部阅读的条件

在 [从短句到真实资料](../00-轻量阅读入门/02-从短句到真实资料.md) 中，连续两次读新短段落，允许查词后能说明主线和限制条件，即可尝试一条真实工作便条或熟悉工具的 3–5 句说明。

旧综合题库供以后检查结构缺口，不再作为开始阅读的资格门槛。
