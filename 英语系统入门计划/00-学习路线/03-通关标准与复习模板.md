# 通关标准与复习模板

## 1. 前两周必须稳定掌握

| 类别 | 必须会 | 测试方式 |
|---|---|---|
| 代词与 be | I/me/my，he/him/his，they/them/their；am/is/are/was/were | 随机快问快答全对 |
| 动词形式 | do/does/did/doing/done 的作用 | 看句说形式和原因 |
| 谓语入口 | 找到 `does not support`、`is loaded`、`must be set` | 20 句全对 |
| 祈使句 | 知道 you 被省略，动词用原形 | 补主语和还原 10 组 |
| 一般现在时 | 一般行为、三单、do/does 否定疑问 | 改写 10 句全对 |
| 主动/被动/状态 | actor + verb + target；be + done；be + adj. | 分类改写 15 句全对 |
| 要求强度 | must/required，should/recommended，may/optional，can | 解释 10 句全对 |
| 条件与顺序 | if/when/unless/before/after/then | 标注 10 句全对 |
| 目的与方法 | to do，for + n./doing，by + doing | 区分口译 10 句全对 |
| 修饰结构 | selected item，data returned，running process | 展开/缩减 10 组全对 |
| 文档片段 | 标题、标签、按钮、错误片段、列表项 | 分类 20 项全对 |

“全对”允许通过多次学习达到。第一次不会很正常；看过答案后觉得懂了不算，隔天不看答案再次做对才算。

## 2. 八周综合验收

| 能力 | 通过标准 |
|---|---|
| 阅读 | 阅读 300-600 词 A2-B1 文章，说出人物/主题、问题、行动和结果 |
| 文档 | 阅读一页入门文档，找出前提、操作、默认行为、条件和错误处理 |
| 词汇 | L0/L1 核心词和词块随机抽测至少 90%，且能放进新句子 |
| 听力 | 对已精读的 1-2 分钟音频，正常速度听懂主要信息并写关键词 |
| 口语 | 不看稿连续说 2 分钟；允许停顿，但能用澄清和修复表达继续 |
| 写作 | 写 100-150 词的消息或说明，读者能准确理解目的和步骤 |
| 自主性 | 能独立制定一周计划、记录错误、选择合适难度并在周末调整 |

## 3. 间隔提取模板

新内容当天理解后，在以下时间点不看答案回忆：

```text
当天结束 → 第 1 天 → 第 3 天 → 第 7 天 → 第 14 天 → 第 30 天
```

每次只复习“想不起来或用错”的项。卡片正面尽量是问题、中文情境或留空句，不是让眼睛再次浏览答案。
