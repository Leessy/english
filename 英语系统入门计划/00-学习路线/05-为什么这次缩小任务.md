# 为什么这次缩小任务

## 1. 旧计划哪里与碎片时间不匹配

旧默认日程安排 60–90 分钟，基础复习还另外增加代词、五形态和随机抽测；学习同一结构需要在概念、速查、例句、技术精读和测试之间切换。前期又要求全对和限时反应。

这些设置让一次学习同时需要选择资料、找词、理解术语、记忆形式和完成输出。根据当前反馈，任务切换和起步负担很可能是难以持续的重要原因；这不等于已经证明它们是唯一原因。

## 2. 高频句式和高频词确实该先学

认识技术名词不自动带来句法理解。应同时学三件事：词在当前句中的意思、它通常和什么词一起出现、整句用它来做什么。

例如 `need` 要与 `need help` 和 `need to open a file` 一起理解。先认出“需要什么”和“需要做什么”的差别，之后再扩充可替换的对象和动作。

“完全掌握所有基础再开始阅读”容易推迟实际练习。新的顺序是：解释一个结构 → 读几个例句 → 换词检验 → 放进短段落 → 反复遇见。熟练度在使用中逐渐提高。

## 3. 方法依据怎样落实

| 来源与观点 | 课程中的处理 |
|---|---|
| NSW 教育部门的认知负荷实践材料建议：给新手示范，把理解所必需的信息放在一起，再逐步增加独立解决问题 | 小课同页词卡、分块例句和答案，减少跨章节检索 |
| The Learning Scientists 的提取练习说明：先从记忆提取，再核对并纠正 | 每次回忆一句；理解题先做后看答案 |
| 该团队的间隔练习说明：把练习分散到多次，并回顾以前材料 | 下一次、几课之后、隔周重复，时间安排允许调整 |
| Extensive Reading Foundation：精读和泛读互补，顺畅阅读需要很少未知语言 | 受控小课学结构，随后读容易的完整短文，太难就减量或换材料 |

上述依据支持设计原则，不证明“每天 10 分钟、12 组递进、每组一个换句题”是普遍最优参数；这些是针对当前碎片时间和跳转困难作出的课程选择。原十四节基础小课降为补漏，避免已认识基础词的人重复从 `I am` 起步。

## 4. 什么算快速入门

第一步是看懂几十个高复用短句，并能读懂换了词的新句。第二步是读 3–8 句的信息，准确把握人物、动作、否定和条件。随后才能稳定阅读更长资料。

只靠一个词汇数字不能保证理解。覆盖率高也可能被陌生句法卡住；反过来，懂结构但缺少核心动词意义，也不能可靠理解。阅读需要两者同时练。

## 5. 查阅来源

- [NSW CESE：Managing cognitive load through effective presentations](https://education.nsw.gov.au/about-us/education-data-and-research/cese/publications/practical-guides-for-educators-/managing-cognitive-load-through-effective-presentations)：示范、整合必要信息、逐步增加独立练习。
- [The Learning Scientists：Retrieval Practice](https://www.learningscientists.org/blog/2016/6/23-1)：提取、核对和再次尝试。
- [The Learning Scientists：Spaced Practice](https://www.learningscientists.org/blog/2016/7/21-1)：分散学习与旧内容回顾。
- [Extensive Reading Foundation Guide](https://erfoundation.org/guide/ERF_Guide.pdf)：第 1–4 页说明精读、泛读及难度匹配；接近 98% 的已知词覆盖是流畅阅读的参考线索，不是保证。
- [British Council A1 Reading](https://learnenglish.britishcouncil.org/free-resources/reading/a1)：适合开始尝试的便条、消息、表格等短文本。
