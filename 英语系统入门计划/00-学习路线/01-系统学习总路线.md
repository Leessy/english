# 系统学习总路线

> 把英语当作一套需要运行的系统：先学最常调用的类型、函数和控制流，再用大量可理解输入形成直觉。

## 1. 英语与编程语言的对应关系

| 编程概念 | 英语对应物 | 阅读时的问题 |
|---|---|---|
| token | 单词、缩写、标点 | 它是普通词、名称还是代码？ |
| type | 名词、动词、形容词、代词等 | 它能放在哪个位置？ |
| function | 动词及其搭配 | `allow` 后面需要谁和什么动作？ |
| runtime | 时态、语态、情态 | 何时发生、谁执行、要求有多强？ |
| control flow | if、when、unless、but、because | 条件、转折、原因和结果是什么？ |
| scope | 短语、从句、括号、列表 | 修饰范围到哪里结束？ |
| standard library | 高频词块和句型 | 能否整块理解和调用？ |

解析一个句子时固定运行：

```text
判断文本类型
  → 找完整动词组或祈使动词
  → 确定谁做什么
  → 识别否定、时间、被动和要求强度
  → 按连接词切分条件、原因、转折和结果
  → 处理修饰成分
  → 只查阻止理解的词
  → 用自己的话复述
```

## 2. 课程依赖关系

```text
句子运行机制 + 动词系统 + 功能词
                │
                ├─ 技术文档常见结构
                ├─ 超高频词块与受控精读
                └─ 声音、重音和朗读基础
                           │
                     8 周基础集中期
                           │
          ┌────────────────┼────────────────┐
       真实阅读          听说互动          长期词汇扩展
          └────────────────┼────────────────┘
                      自主学习循环
```

## 3. 两个时间尺度

### 基础集中期：8 周

- 前 2 周：核心解析器。基础内容反复学习，关键项目要求接近 100%。
- 第 3-4 周：超高频词块、发音听辨、日常功能表达。
- 第 5-6 周：技术文档和生活文章精读，开始短口述和短写作。
- 第 7-8 周：真实材料迁移、提高熟练度、建立自己的学习流程。

基础薄弱时，一个“学习日”可以拆成两个自然日；8 周可以延长到 12-16 周，但不要跳过出口测试。

### 自主发展期：至少 6-12 个月并长期持续

此阶段不再追求“学完英语”，而是每周保持四种活动：可理解输入、真实输出、刻意学习、熟练度训练。详细方法见 [`04-长期学习系统.md`](./04-长期学习系统.md)。

## 4. 什么必须 100%，什么不必

前两周要求接近 100% 的是：代词与 be、完整动词组、一般现在时、祈使句、否定、被动、情态要求、条件词、基础分词结构，以及教材中的受控句。

不要求 100% 的是：所有不规则动词、低频书面词、专业名词、复杂从句名称和真实文档中的每个词。它们应在后续阅读中按频率逐步获得。

## 5. 可自学的真正标准

你不需要“完全不用中文或词典”。达到以下状态就已越过最困难的门槛：

1. 能从 300-600 词的 A2-B1 文章或入门文档中找出目的、动作、条件和结果。
2. 每 100 词未知词不超过约 5-10 个；更难时知道主动换简单材料。
3. 能用 5-8 个简单英文句复述要点或说明一个问题。
4. 能听懂已经精读过的材料，并跟读到节奏基本连贯。
5. 能把错误归类，并找到对应词典、语法或上下文证据。
6. 能自己计划一周、记录输入输出、周末评估并调整难度。
