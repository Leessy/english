# 系统学习总路线

默认使用 [每次练一句](../../英语考试快速复习站/index.html?view=reading)，配套说明见 [从熟词到复杂句](../00-轻量阅读入门/03-从熟词到复杂句.md)。适合认识常见词但读句不熟的人；十四节小课仅作补漏。本页不是每天要读的任务。

## 1. 为什么认识技术词仍然看不懂句子

知道 file、server 等名称，解决的是“句子谈什么”；还需要认出 `does not`、`can`、`is saved`、`if` 等关系，才能知道“发生什么、是否允许、有什么条件”。

先把高价值词放进完整句子，再保持结构、替换少量词：

```text
The file is ready.       文件准备好了。
The room is ready.       房间准备好了。
The file is not ready.   文件还没准备好。
```

room 是房间。第二句只换对象，第三句加入否定。这样能检验你是否真正认出结构。

## 2. 优先熟悉的三类词

| 优先级 | 内容 | 学法 |
|---|---|---|
| 第一层：决定句意 | don’t need to、can be、has been、if、before、unless | 成块识别动作、否定、时间和条件；已会的代词不再单独重背 |
| 第二层：常见动作和词块 | have、use、need、open、save；need to、ask for help | 连同对象、搭配学习，不能只记一个中文词义 |
| 第三层：当前场景的词 | 工作已见过的 file/app 等；日常 book/room 等 | 先复用熟词，再逐步加入实际阅读所需新词 |

这里是课程优先级，不是固定词频榜。每次只精记最多 3 个不熟的高价值项目。重复遇到又影响理解的词，比一次性低频词更值得记。

## 3. 分三个阶段走

| 阶段 | 实际任务 | 前进信号 |
|---|---|---|
| 结构熟练 | 复习站 12 组递进训练，每次约 10 分钟 | 能在换句题中认出完整动作、修饰和小句关系 |
| 短段阅读 | 一次 3–8 句留言或操作说明 | 能说出目的、条件和动作顺序，允许查词 |
| 扩展自学 | 同一主题持续阅读，逐步加听说 | 能自己判断卡在词义、结构还是领域知识 |

第一阶段可以先按 4–8 周试行；遇到忙周允许延长。这是执行节奏，不是等级或无障碍阅读承诺。

## 4. 怎样理解“像中文一样读”

中文理解依赖长期积累的词义、搭配、语序和常识。英语可以逐步形成类似熟悉感，但“认识所有代词”只是其中一部分。

先让常用句子反复出现，再练未见过的同结构句，最后读完整段落。对于熟悉材料，可以直接理解意思，不必每句标语法术语；遇到读不通的句子再拆解。

不能把所有陌生词都略过：否定、条件、关键动作和定义词需要确认。普通对象名可以先猜位置，读完后按任务需要核实。

## 5. 碎片时间怎么持续

- 绑定一个现成时刻，例如午饭后坐下的前 10 分钟。
- 本次结束只留一行“下次从哪句开始”，降低重启成本。
- 下次开头回忆上一句；学完约三课时用一次时间重读旧句，隔一周再抽几句。
- 连续漏学后从原位置恢复，不做补偿式长课。
- 累了就做 3 分钟的一句任务；3 分钟是保留连续接触的最低动作，不等于充足学习量。

方法依据与旧计划问题见 [为什么这次缩小任务](./05-为什么这次缩小任务.md)，只在想了解设计原因时读。
