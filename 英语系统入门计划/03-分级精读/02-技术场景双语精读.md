# 技术场景双语精读

> 以下为原创受控技术英语。重点不是专业知识，而是反复识别指令、默认行为、条件、被动、分词修饰和错误处理。

## 1. Before You Install（A2）

### English

Before you install the tool, make sure your system has at least two gigabytes of free space. The tool is available for Windows, macOS, and Linux. Download the file for your operating system. Do not rename the file because the installer uses its original name.

Close other applications and open the installer. If a security message appears, check that the publisher name is Example Tools. Then select **Continue**. The installation usually takes less than two minutes. When it finishes, open the tool and create a test project. If the project opens without an error, the installation was successful.

### 中文核验

安装该工具之前，请确保系统至少有两 GB 可用空间。此工具支持 Windows、macOS 和 Linux。请下载与你的操作系统对应的文件。不要重命名该文件，因为安装程序会使用它的原始名称。

关闭其他应用程序并打开安装程序。如果出现安全提示，请检查发布者名称是否为 Example Tools，然后选择“继续”。安装通常不到两分钟。安装完成后，打开工具并创建一个测试项目。如果项目打开时没有报错，说明安装成功。

**结构检查**：圈出 6 个祈使动词；找出两个 if 条件；解释 `was successful` 为什么不是被动动作。

## 2. Default Settings（A2+）

### English

The application saves new files in the Documents folder by default. You can change this location in **Settings > Storage**. Select a folder that your account is allowed to access. A network folder may be used, but it must be available when the application starts.

Automatic backup is enabled by default. A copy is created every ten minutes and kept for seven days. To change the backup interval, enter a value between 5 and 60. Setting the value to 0 disables automatic backup. This is not recommended unless another backup system is already in use.

### 中文核验

默认情况下，应用程序把新文件保存在“文档”文件夹。你可以在“设置 > 存储”中更改此位置。请选择当前账户有权访问的文件夹。可以使用网络文件夹，但应用程序启动时该文件夹必须可用。

自动备份默认开启。系统每十分钟创建一个副本，并将其保留七天。如需修改备份间隔，请输入 5 到 60 之间的数值。将该值设为 0 会关闭自动备份。除非已经在使用另一套备份系统，否则不建议这样做。

**结构检查**：找出三个被动结构；说明 `To change` 表示什么；解释 unless 后的条件。

## 3. Sending an API Request（B1）

### English

The `/users` endpoint returns a list of users. Send a GET request and include your access token in the `Authorization` header. The token identifies your account and must not be shared.

By default, the response contains the first twenty users. Use the `limit` parameter to request a different number. The maximum allowed value is 100. If the value is missing, 20 is used. If it is greater than 100, the server returns a `400 Bad Request` response.

The response body is a JSON object containing `data` and `next_page`. When `next_page` is not null, send another request with that value to retrieve the next group of users.

### 中文核验

`/users` 端点返回用户列表。请发送 GET 请求，并在 `Authorization` 请求头中加入访问令牌。该令牌用于识别你的账户，不得分享给他人。

默认情况下，响应包含前二十名用户。使用 `limit` 参数可以请求不同数量的用户，允许的最大值为 100。如果没有提供该值，系统会使用 20；如果该值大于 100，服务器会返回 `400 Bad Request` 响应。

响应正文是一个包含 `data` 和 `next_page` 的 JSON 对象。当 `next_page` 不为 null 时，请带上该值再次发送请求，以获取下一组用户。

**结构检查**：写出 input/action/output/error 四格摘要；找出两个分词修饰结构。

## 4. A Useful Bug Report（B1）

### English

A useful bug report allows another person to see the problem without guessing. Start with a short title that describes the visible result, such as “Export stops at 80%.” Then list the exact steps needed to reproduce the problem.

Include what you expected to happen and what actually happened. Add the application version, operating system, and complete error message. If possible, attach a small sample file that does not contain private information. Do not attach passwords, access tokens, or customer data.

Before you submit the report, repeat the steps once. This helps you find missing details and confirm that the problem can still be reproduced.

### 中文核验

一份有用的缺陷报告应让他人无需猜测就能看到问题。先用简短标题描述可见结果，例如“导出进度到 80% 时停止”，然后列出重现问题所需的准确步骤。

请说明你原本预期发生什么，以及实际发生了什么。加入应用版本、操作系统和完整错误信息。如果可能，请附上一个不含私人信息的小型示例文件。不要附上密码、访问令牌或客户数据。

提交报告前，请再重复一次这些步骤。这能帮助你发现遗漏的细节，并确认问题仍然可以重现。

**结构检查**：找出 `allow + object + to do`、`needed to do` 和 `what` 从句；用英文写一个自己的错误标题。

## 5. Permission Problem（B1）

### English

If the application is unable to save a file, first check the folder permissions. The current user must have write access to the target folder. On a shared system, access may be controlled by an administrator.

Do not run the application as an administrator only to avoid the error. Doing so may give it access to files that should remain protected. Instead, select a folder owned by your account or ask the administrator for the minimum permission required.

After the permission is changed, close and reopen the application. Some applications read permissions only when they start. If the error continues, check whether the file is already open in another program.

### 中文核验

如果应用程序无法保存文件，请先检查文件夹权限。当前用户必须拥有目标文件夹的写入权限。在共享系统中，访问权限可能由管理员控制。

不要只是为了避开这个错误就以管理员身份运行应用程序。这样做可能会让它访问原本应受保护的文件。请选择当前账户拥有的文件夹，或向管理员申请完成任务所需的最低权限。

权限更改后，请关闭并重新打开应用程序。有些应用只在启动时读取权限。如果错误仍然存在，请检查该文件是否已在另一个程序中打开。

**结构检查**：解释 `Doing so` 指代什么；比较 `may`、`must` 和 `should` 的力度。

## 6. Moving to a New Version（B1+）

### English

Version 4 changes the format used to store project settings. Existing projects are converted the first time they are opened. This conversion cannot be undone, and projects saved in version 4 cannot be opened in version 3.

Before upgrading, back up all projects and confirm that the backup can be restored. If your team shares projects, everyone should upgrade at the same time. Otherwise, some members may be unable to open files changed by others.

Two old options, `quick_mode` and `legacy_output`, are no longer supported. Remove them from your configuration before starting the new version. Use `fast_mode` instead of `quick_mode`. There is no direct replacement for `legacy_output`; see the migration guide for the recommended workflow.

### 中文核验

版本 4 更改了用于存储项目设置的格式。现有项目第一次打开时会被转换。此转换无法撤销，而且在版本 4 中保存的项目不能再由版本 3 打开。

升级前，请备份所有项目并确认备份能够恢复。如果团队共享项目，所有人应同时升级，否则部分成员可能无法打开其他人修改过的文件。

两个旧选项 `quick_mode` 和 `legacy_output` 已不再受支持。启动新版本前，请将它们从配置中删除。请使用 `fast_mode` 替代 `quick_mode`。`legacy_output` 没有直接替代项；推荐流程请参阅迁移指南。

**结构检查**：找出四个被动；解释 `the first time`、`otherwise` 和 `instead of`；列出升级的风险和预防动作。
