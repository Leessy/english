## A 级：解析句子必须秒懂的功能词

### 代词、限定词与数量

| 词 | 核心意思 | 关键用法 |
|---|---|---|
| I / me / my | 我 / 我（宾语）/ 我的 | I call him; he calls me; my phone |
| you / your | 你（们）/ 你（们）的 | 单复数同形 |
| he / him / his | 他 / 他（宾语）/ 他的 | he helps us; ask him |
| she / her / hers | 她 / 她（宾语）或她的 / 她的东西 | her file; the file is hers |
| it / its | 它 / 它的 | it's = it is/has；its = 它的 |
| we / us / our | 我们 / 我们（宾语）/ 我们的 | we need it; help us |
| they / them / their | 他们 / 他们（宾语）/ 他们的 | they sent their reply |
| this / that | 这个 / 那个；这件事 / 那件事 | 也可指代前文整件事 |
| these / those | 这些 / 那些 | 后接复数名词 |
| some / any | 一些 / 任何、一些 | any 常用于否定、疑问、“任何” |
| each / every | 每一个 / 每一个 | 通常按单数处理 |
| all / both | 所有 / 两者都 | not all = 并非所有 |
| either / neither | 两者任一 / 两者都不 | either A or B; neither A nor B |
| another / other | 另一个 / 其他的 | another + 单数；other + 复数/不可数 |
| few / little | 几乎没有 | few + 可数复数；little + 不可数 |
| many / much | 很多 | many + 可数复数；much + 不可数 |
| more / most | 更多 / 大多数或最多 | more than; most users |

### 连接和逻辑

| 词 | 准确理解 | 常见结构 |
|---|---|---|
| and / or | 并且 / 或者 | A and B; A or B |
| but / however | 但是 / 然而 | however 常与句子用逗号隔开 |
| so / therefore | 所以 / 因此 | 引出结果 |
| because / since | 因为 / 由于、自从 | since 需根据语境判断原因或时间 |
| if / unless | 如果 / 除非 | unless = if ... not |
| although / though | 虽然、尽管 | 不和 but 同时连接同一对分句 |
| while / whereas | 当……时、而 / 而、然而 | 常表对比 |
| before / after | 在……之前 / 之后 | 可作介词或连词 |
| when / while | 当……时 | while 常强调持续过程 |
| until | 直到 | not ... until = 直到……才 |
| as | 当、由于、按照、像 | 必须根据结构选义 |
| than / as ... as | 比 / 和……一样 | 比较结构 |
| that / which / who | 那个；引导从句 / 哪个 / 谁 | 长句中常是从句边界 |
| whether | 是否 | whether ... or not |

## 如何记这份词表

- 每天选 10 个条目，只要求“看到能反应”；其中 3 个用来造句。
- 动词必须带结构记，如 `allow someone to do`、`prevent someone from doing`。
- 每周从分级文章、工作文档和日常对话中各收集少量真实句子，优先复习在真实语境中重复遇到的词。
- 同一个词在不同语境下不要强行用同一个中文。例如 `run` 可以是“跑”、“运行”、“经营”或“执行”。
