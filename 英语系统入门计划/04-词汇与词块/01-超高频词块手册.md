# 超高频词块手册：第一批 100 个调用单元

> 词块不是必须逐字翻译的“短语题”，而是可以整体识别和替换参数的调用单元。前 8 周反复使用本册；每次学 5-10 个，先听懂和说对，再追求拼写。

## 学习方法

以 `I need to + 动词原形` 为例：

1. 理解固定功能：表示“我需要做……”。
2. 看清接口：`to` 后接动词原形。
3. 替换参数：`check / wait / update / ask`。
4. 在真实情境中回答：`What do you need to do?`
5. 按 1、3、7、14、30 天复测。

## A. 状态、身份和存在

| 词块 | 核心理解与接口 | 例句与准确翻译 |
|---|---|---|
| `This is + 名词` | 这是……；介绍眼前事物 | `This is the main page.` 这是主页。 |
| `That is + 名词` | 那是……；指较远或刚提到的事物 | `That is the reason.` 那就是原因。 |
| `It is + 形容词` | 它/这处于某种状态 | `It is important.` 这很重要。 |
| `There is + 单数/不可数名词` | 有……；引入一个事物 | `There is a problem.` 有一个问题。 |
| `There are + 复数名词` | 有多个…… | `There are two options.` 有两个选项。 |
| `have/has + 名词` | 有、拥有；也可表示包含 | `The app has a search box.` 这个应用有一个搜索框。 |
| `be ready to + 动词` | 已准备好做…… | `We are ready to start.` 我们准备好开始了。 |
| `be available` | 可用、有空、可获得；由语境决定 | `The update is now available.` 这个更新现在可以使用了。 |
| `be able to + 动词` | 能够做……，强调实际能力或条件 | `You will be able to open the file.` 你将能够打开该文件。 |
| `be different from + 名词` | 与……不同 | `This version is different from the old one.` 这个版本与旧版本不同。 |

## B. 需要、计划和尝试

| 词块 | 核心理解与接口 | 例句与准确翻译 |
|---|---|---|
| `need to + 动词` | 需要做…… | `I need to check the result.` 我需要检查结果。 |
| `want to + 动词` | 想做……，日常直接表达 | `I want to learn how it works.` 我想了解它是如何工作的。 |
| `would like to + 动词` | 想要做……，比 want 更礼貌 | `I'd like to ask a question.` 我想问一个问题。 |
| `have to + 动词` | 因规则或情况不得不做 | `You have to sign in first.` 你必须先登录。 |
| `plan to + 动词` | 计划做…… | `We plan to update the service.` 我们计划更新这项服务。 |
| `try to + 动词` | 努力/尝试完成某动作 | `Try to keep the sentence short.` 尽量让句子简短。 |
| `decide to + 动词` | 决定做…… | `They decided to wait.` 他们决定等待。 |
| `be going to + 动词` | 打算或即将做…… | `I'm going to test it again.` 我打算再测试一次。 |
| `be supposed to + 动词` | 按计划、规则或预期应该做 | `The button is supposed to open the menu.` 按设计，这个按钮应该打开菜单。 |
| `used to + 动词` | 过去常常，现已不同；不要和 `be used to` 混淆 | `I used to work at night.` 我过去常在晚上工作。 |

## C. 想法、判断和不确定性

| 词块 | 核心理解与接口 | 例句与准确翻译 |
|---|---|---|
| `I think + 句子` | 我认为…… | `I think this is the right file.` 我认为这就是正确的文件。 |
| `I don't think + 句子` | 我认为不……；英语常把否定放在 think 前 | `I don't think it is ready.` 我觉得它还没准备好。 |
| `I don't know + 疑问词从句` | 不知道某信息 | `I don't know where the file is.` 我不知道文件在哪里。 |
| `I'm not sure + 句子/疑问词从句` | 我不确定…… | `I'm not sure whether it is safe.` 我不确定这样是否安全。 |
| `It depends on + 名词` | 这取决于…… | `It depends on the file size.` 这取决于文件大小。 |
| `I agree with + 人/观点` | 同意某人或某观点 | `I agree with your suggestion.` 我同意你的建议。 |
| `I mean + 句子` | 我的意思是……；用于修正或解释 | `I mean we should check it first.` 我的意思是我们应该先检查一下。 |
| `In my opinion, + 句子` | 在我看来……，比 I think 稍正式 | `In my opinion, the first option is simpler.` 在我看来，第一个选项更简单。 |
| `As far as I know, + 句子` | 据我所知，保留不完全确定 | `As far as I know, the service is free.` 据我所知，这项服务是免费的。 |
| `It is likely to + 动词` | 很可能会…… | `The change is likely to cause an error.` 这个改动很可能会引发错误。 |

## D. 澄清、确认和维持对话

| 词块 | 核心理解与接口 | 例句与准确翻译 |
|---|---|---|
| `Could you repeat that?` | 能请你重复一遍吗？ | `Sorry, could you repeat that?` 抱歉，能请你重复一遍吗？ |
| `Could you speak more slowly?` | 能说慢一点吗？ | `Could you speak a little more slowly?` 你能稍微说慢一点吗？ |
| `What do you mean by + 名词?` | 你说的……是什么意思？ | `What do you mean by “local”?` 你说的“本地”是什么意思？ |
| `Do you mean + 句子?` | 你是说……吗？用于确认理解 | `Do you mean I should restart it?` 你是说我应该重启它吗？ |
| `How do I + 动词?` | 我该怎样做……？ | `How do I change the password?` 我该怎样修改密码？ |
| `Can you show me + 名词/从句?` | 你能给我看……吗？ | `Can you show me where the setting is?` 你能告诉我这个设置在哪里吗？ |
| `Let me check.` | 让我确认一下，不等于“允许我检查”式硬译 | `Let me check the schedule.` 我确认一下日程。 |
| `Just a moment.` | 请稍等一下 | `Just a moment. I'll open the file.` 请稍等，我来打开文件。 |
| `That's right.` | 对，就是这样 | `Yes, that's right.` 是的，没错。 |
| `Did I get that right?` | 我理解得对吗？ | `I need to send it today. Did I get that right?` 我需要今天发出，对吗？ |

## E. 时间、顺序和过程

| 词块 | 核心理解与接口 | 例句与准确翻译 |
|---|---|---|
| `first of all` | 首先，开始说明多个要点 | `First of all, check the connection.` 首先，检查连接。 |
| `at first` | 起初；描述早期状态，不等于“首先做” | `At first, the task seemed difficult.` 起初，这项任务看起来很难。 |
| `and then` | 然后；连接连续动作 | `Save the file and then close it.` 保存文件，然后关闭它。 |
| `after that` | 在那之后 | `After that, restart the app.` 之后，重启应用。 |
| `before + 名词/doing/句子` | 在……之前 | `Back up the data before you continue.` 继续之前先备份数据。 |
| `as soon as + 句子` | 一……就…… | `Let me know as soon as you finish.` 你一完成就告诉我。 |
| `at the same time` | 同时；也可表示“不过，另一方面” | `Two users can edit the file at the same time.` 两个用户可以同时编辑该文件。 |
| `for now` | 目前、暂时 | `For now, use the old version.` 目前先使用旧版本。 |
| `from now on` | 从现在起 | `From now on, save a copy first.` 从现在起，先保存一个副本。 |
| `in the end` | 最后、最终结果 | `In the end, we found the cause.` 最后，我们找到了原因。 |

## F. 原因、结果、目的和转折

| 词块 | 核心理解与接口 | 例句与准确翻译 |
|---|---|---|
| `because + 句子` | 因为后面是完整原因句 | `It failed because the key was missing.` 它失败了，因为缺少密钥。 |
| `because of + 名词` | 因为后面是名词性原因 | `It failed because of a network error.` 它因网络错误而失败。 |
| `so + 结果句` | 所以、因此；口语和普通说明常用 | `The file was large, so the upload took longer.` 文件很大，所以上传花了更长时间。 |
| `so that + 句子` | 以便、为了使…… | `Add a note so that others can understand the change.` 加一条说明，以便其他人理解这项改动。 |
| `That's why + 句子` | 那就是为什么…… | `The path is wrong. That's why it cannot find the file.` 路径错了，所以它找不到文件。 |
| `as a result` | 因此、结果是；书面连接 | `The server stopped. As a result, the page was unavailable.` 服务器停止了，因此页面无法访问。 |
| `but + 句子` | 但是，直接连接转折 | `The command is simple, but it takes time.` 这个命令很简单，但执行需要时间。 |
| `however, + 句子` | 然而；较书面，通常用标点隔开 | `The first method is faster. However, it is less safe.` 第一种方法更快，但安全性较低。 |
| `even though + 句子` | 尽管事实如此，结果仍相反 | `It worked even though the warning appeared.` 尽管出现了警告，它仍然正常运行。 |
| `instead of + 名词/doing` | 不做前者，而做后者 | `Use a copy instead of changing the original file.` 使用副本，不要修改原文件。 |

## G. 条件、范围和数量

| 词块 | 核心理解与接口 | 例句与准确翻译 |
|---|---|---|
| `if possible` | 如果可能 | `Use a wired connection if possible.` 如果可能，请使用有线连接。 |
| `if necessary` | 如有必要 | `Restart the service if necessary.` 如有必要，重启服务。 |
| `if not` | 如果不是/如果不这样 | `Check the result. If not, try again.` 检查是否成功；如果没有成功，请重试。 |
| `unless + 句子` | 除非；相当于 if ... not | `Do not delete it unless you have a backup.` 除非已有备份，否则不要删除它。 |
| `as long as + 句子` | 只要某条件满足 | `You can use it as long as the key is valid.` 只要密钥有效，你就可以使用它。 |
| `in case + 句子` | 以防某事发生，提前准备 | `Save a copy in case something goes wrong.` 保存一个副本，以防出现问题。 |
| `a lot of + 名词` | 很多，可接可数复数或不可数名词 | `The process uses a lot of memory.` 这个进程占用大量内存。 |
| `a little + 不可数名词` | 少量；`a little` 也可表示“稍微” | `It needs a little more time.` 它还需要一点时间。 |
| `more than + 数量/名词` | 多于、超过 | `The task takes more than ten minutes.` 这项任务需要十多分钟。 |
| `less than + 数量/不可数名词` | 少于、不到 | `The file is less than one megabyte.` 该文件不到一兆字节。 |

## H. 高频任务动作

| 词块 | 核心理解与接口 | 例句与准确翻译 |
|---|---|---|
| `make sure + 句子` | 确保、确认某条件成立 | `Make sure the file name is correct.` 请确保文件名正确。 |
| `find out + 信息` | 查明、弄清未知信息 | `We need to find out what caused the error.` 我们需要查明错误的原因。 |
| `look for + 目标` | 寻找尚未找到的东西 | `Look for the config file.` 查找配置文件。 |
| `look at + 对象` | 看、检查一个对象 | `Let's look at the example.` 我们来看一下这个例子。 |
| `work on + 任务` | 处理、从事某任务 | `I'm working on the update.` 我正在处理这次更新。 |
| `ask for + 事物` | 请求获得某物或帮助 | `Ask for help if you need it.` 如果需要，请寻求帮助。 |
| `wait for + 名词` | 等待某人或某物 | `Wait for the process to finish.` 等待该进程完成。 |
| `set up + 对象` | 安装配置好，使其可用 | `Set up your account first.` 请先设置好你的账户。 |
| `turn on / turn off + 设备/功能` | 打开/关闭设备或功能 | `Turn off the device before you clean it.` 清洁设备前请将其关闭。 |
| `try again` | 再试一次 | `Check the password and try again.` 检查密码，然后重试。 |

## I. 技术文档高频结构

| 词块 | 核心理解与接口 | 例句与准确翻译 |
|---|---|---|
| `be used to + 动词` | 被用于做……；这里 used 是过去分词 | `This command is used to create a file.` 这个命令用于创建文件。 |
| `be used for + 名词/doing` | 用于某用途 | `This option is used for testing.` 此选项用于测试。 |
| `depend on + 名词` | 依赖、取决于 | `The result depends on the input.` 结果取决于输入。 |
| `refer to + 名词` | 指的是；参阅 | `Here, “client” refers to the app.` 这里的“客户端”指该应用。 |
| `by default` | 默认情况下 | `The feature is disabled by default.` 默认情况下，此功能处于禁用状态。 |
| `be required to + 动词` | 被要求必须做…… | `Users are required to sign in.` 用户必须登录。 |
| `allow + 人/对象 + to + 动词` | 允许某人/对象做…… | `The setting allows users to share files.` 此设置允许用户共享文件。 |
| `be unable to + 动词` | 无法做……，较正式 | `The app is unable to connect.` 该应用无法连接。 |
| `be available in/for/on` | 可在某版本/对象/平台使用 | `The feature is available in version 3.` 版本 3 提供此功能。 |
| `work with + 对象` | 与……配合使用、兼容 | `This tool works with JSON files.` 此工具支持处理 JSON 文件。 |

### 三种 used 结构不要混在一起

| 结构 | 意思 | 例句 |
|---|---|---|
| `used to + 动词原形` | 过去常做，现在通常不再如此 | `I used to work at night.` 我过去常在晚上工作。 |
| `be used to + 动词原形` | 被用于做某事；used 是 use 的过去分词 | `The key is used to open the door.` 这把钥匙用于开门。 |
| `be used to + 名词/doing` | 习惯于某事；这里 to 是介词 | `I am used to working at night.` 我已经习惯在晚上工作。 |

## J. 工作沟通和错误处理

| 词块 | 核心理解与接口 | 例句与准确翻译 |
|---|---|---|
| `take a look at + 对象` | 看一下、检查一下 | `Could you take a look at this error?` 你能帮我看一下这个错误吗？ |
| `let + 人 + know` | 告知某人 | `Please let me know when it is ready.` 准备好后请告诉我。 |
| `get back to + 人` | 稍后回复某人 | `I'll check and get back to you.` 我确认后再回复你。 |
| `follow up on + 事项` | 跟进某事 | `I'm following up on your request.` 我正在跟进你的请求。 |
| `on time` | 按时，不早不晚 | `The meeting started on time.` 会议准时开始。 |
| `in progress` | 正在进行中 | `The update is still in progress.` 更新仍在进行中。 |
| `go wrong` | 出问题、出差错 | `What could go wrong?` 可能会出什么问题？ |
| `something is wrong with + 对象` | 某对象有问题 | `Something is wrong with the connection.` 连接出了问题。 |
| `doesn't work` | 不起作用、无法运行 | `The old command doesn't work here.` 旧命令在这里不起作用。 |
| `run into a problem` | 遇到问题 | `We ran into a problem during setup.` 我们在设置过程中遇到了问题。 |

## 自测规则

随机抽一个词块，完成四项才算掌握：

1. 看到英文能直接说出功能，不逐字拼译。
2. 根据中文情境能说出英文骨架。
3. 能替换至少两个参数造新句。
4. 能在精读文章、工作消息或对话中正确识别。

单元 A-D 是第 3-4 周口语核心；E-G 是句子逻辑核心；H-J 是工作和文档核心。忘记很正常，按间隔重复，不要为一次背不住而增加新词量。
